# Ammo.js (物理演算)

Bullet Physics を WebAssembly にした ammo.js。MMD モデルの剛体 (髪・スカートなど) の物理演算に使う。
three.js r171 (npm の three@0.171.0) の `examples/jsm/libs/` にあったものを、そのまま置いている
(three.js は r172 で MMD 用の部品と一緒に外したため)。アプリと同じ場所から配るので、インターネットにつながっていなくても動く。

ライセンス: zlib (ammo.js / Bullet Physics)。https://github.com/kripken/ammo.js
