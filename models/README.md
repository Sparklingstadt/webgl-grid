# models/ — PMX モデル置き場

自分の PMX モデル（.pmx とテクスチャのフォルダ）を、モデルごとのフォルダにして置く場所です。
アプリを起動すると、ここにあるモデルの一覧がビューポートの左下に出て、選ぶとテクスチャ付きで読み込みます（「ファイル > models フォルダから読み込む…」でも開けます）。
一覧は、アプリを配っているサーバー（`npm run dev`・`npm run preview`・MCP サーバー）が教えます。直下のフォルダごとに、中の .pmx をモデルに、そのフォルダの画像をテクスチャにします（.vmd や曲は読み込みません）。

```
models/
  げのげ式初音ミク/
    げのげ式初音ミク.pmx
    Tex_Miku/      … テクスチャ
    readme.txt     … モデルの規約 (一緒に置いておく)
```

**このフォルダの中身は Git に入りません**（`.gitignore` で、この README 以外を除いています）。
モデルの多くは規約で再配布・改変後の配布が禁じられているので、リポジトリに入れたり公開したりしないでください。
