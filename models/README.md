# models/ — PMX モデル置き場

自分の PMX モデル（.pmx とテクスチャのフォルダ）を、モデルごとのフォルダにして置く場所です。
アプリを起動すると、ここにあるモデルの一覧がビューポートの左下に出て、選ぶとテクスチャ付きで読み込みます（「ファイル > models フォルダから読み込む…」でも開けます）。
一覧は、アプリを配っているサーバー（`npm run dev`・`npm run preview`・MCP サーバー）が教えます。直下のフォルダごとに、中の .pmx をモデルに、そのフォルダの画像をテクスチャにします。

モーション（.vmd）も、models/ の中のどこに置いても一覧の「モーション」に出ます（例: `models/モーション/踊り.vmd`）。選ぶと、選んでいるモデルに付けます（選んでいなければ、置いてあるモデル全員に。カメラのモーションはカメラに）。ポーズと表情（.vpd）も同じように、一覧の「ポーズ・表情」から選んで当てられます（例: `models/ポーズ/腕を上げる.vpd`）。
モデルを読み込むときに、同じフォルダの .vmd・.vpd が勝手に付くことはありません。

```
models/
  げのげ式初音ミク/
    げのげ式初音ミク.pmx
    Tex_Miku/      … テクスチャ
    readme.txt     … モデルの規約 (一緒に置いておく)
  モーション/
    踊り.vmd
  ポーズ/
    腕を上げる.vpd
```

**このフォルダの中身は Git に入りません**（`.gitignore` で、この README 以外を除いています）。
モデルの多くは規約で再配布・改変後の配布が禁じられているので、リポジトリに入れたり公開したりしないでください。
