|---|---|---|
| 1 | コントローラーの値は物ごとの値 (objectData) にするので、取り消しの対象になる (第 4 の計画では場面の値で取り消さなかった) | スライダーを動かすたびに取り消しの段が増える (ドラッグはまとめている) |
| 2 | アクセサリの回転の順は、資料が見つからないので MMD のボーンと同じ (YawPitchRoll(Ry, Rx, Rz)) にし、「未確認」と書いた | 2 つ以上の軸を回したアクセサリを読むエフェクトの向きが違う。1 行で直せる |
| 3 | アクセサリの Rx・Ry・Rz は度で持って見せ、.fx の CONTROLOBJECT にはラジアンで渡す (MME の決まりとして聞いたもので未確認) | 回転を読むエフェクトに 57 倍の値が渡る。1 行で直せる |
| 4 | CONTROLOBJECT の名前は、種類を問わず場面の並びで最初に合った物 (なければステージ) | 同じ名前のモデルがコントローラーの物より先にあると、モデルの値を読む |
| 5 | アクセサリのオン・オフは、ビューポートと書き出しの両方で隠す | 1 行で直せる |

| 7 | サイドバーの MME の欄は、MME の物ならいつも、モデルは MME 互換のときだけ出す | Sidebar.tsx の 1 行 |
| 8 | デスクトップ版にも fx フォルダ (書類/webgl-grid/fx) とメニューを足した (計画のファイルの一覧になかった) | electron/main.ts の数行 |

## 最後のレビューで直したもの

- .fx のフォルダを読む前に .emm を読むと、見つからない .fx の割り当てが消えていた (ステージは取り消せない)。見つからない行は今の割り当てを残し、全部見つからない物・ステージには手を付けない
- 別のステージにパラメータの値が引き継がれていた
- `effectParams` が MME の決まった名前の変数 (`use_toon` など) を出していた
- README の「ray.fx のパラメータ」(ray.fx に変えられるものはない。設定は ray.conf)
- 古いコントローラーの名前を直して移したお知らせが、移せなかったときにも出ていた
- タブの矢印キーが Alt・Ctrl・Cmd 付きのもの (ブラウザの戻る) も止めていた

## 手で確かめてほしいもの

- デスクトップ版 (`npm run electron`) で、書類/webgl-grid/fx ができて「fx/ から選ぶ」と「fx フォルダを開く」が出るか
- 書き出した .emm を本物の MMD (MME) で読めるか ([Object] をファイル名だけで書いている)
- アクセサリの回転の順と、回転をラジアンで渡すこと (決めたこと 2・3)

## 次に回したこと

### すぐ直すとよいもの (後片付け)
- MME の値の欄が、再生中に毎フレーム全体を描き直す (◆ だけにする)。値が動いているあいだ、欄の中身を毎フレーム作り直す
- `commands.ts` が 270 行増えた (MME のコマンドを別のファイルに分ける)
- パラメータの値を、部分 × pass × タブごとに毎回作り直す (Ray-MMD はパラメータがないので今は 0)
- .emm: 1 つの物の全部の .fx が見つからないとき以外は、.emm にない枠は消える (設計書の「置き換え」のまま)。`matchFxPath` が行数 × ファイル数。Shift_JIS にない文字は `?` になる (書いてある)。拡張子だけの同じ名前の .fx を当てる
- `mme_set_values` が空の配列を受け付ける、コントローラーの項目の名前を確かめない。エラーの文が日本語と翻訳済みで混ざる
- ステージの割り当てが、別のステージ・ステージなしで読んだ古いプロジェクトで黙って当たらない (お知らせがない)
- 複製したアクセサリが `ray.x.001` になり、.emm では `Pmd` として書かれる
- テストの穴: 割り当ての選択肢の同じ名前のフォルダ・見つからない参照、動画のキーの比べる側、古いプロジェクトのアクセサリの値、MCP のコントローラーの値の効き目

### 第 5 の計画 (ほかの MME エフェクト)
- 同じ .fx を 2 つのアクセサリに当てると、レンダーターゲットを共有する
- `*.x` という名前のコントローラーにスライダーが出ない
- Script の `LoopGetIndex` の値が、物ごとのパラメータの値より強い
