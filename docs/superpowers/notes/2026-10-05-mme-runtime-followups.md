## 次に回したこと

### 第 3 の計画 (割り当ての保存・UI・MCP)
- `MmeRenderer.ts` (約 700 行) を、材質の状態とオーバーレイに分ける
- `Skinner.plain()` は頂点が変わるたびにジオメトリを作り直す。MoGraph・PolyFX と合わせて、その場で書き換える形にする。groups/drawRange も見ていない
- 変形した (デフォーマのある) MMD のモデルの複製は描けない (README に書いた)
- 毎フレームの MaterialState の作り直し、`ScriptTargets` の割り当て、`publish()` の JSON 化
- `setObjectEffect` が、変わっていなくても `changed` を出す
- ステージだけを差し替えたときは、古いトゥーンの画像が次の掃除まで残る
- MCP の `screenshot` は `whenReady` を待たない (`renderPng` は待つ)

### 第 4 の計画 (Ray-MMD)
- `Clear=Depth` は深度だけを消し、ステンシルを消さない。MME は両方を消し、`ray.fx` は `ClearSetStencil` のあとに `Clear=Depth` を使う。`PostChain.ts`/`script.ts` で `what === 'depth'` のときにステンシルも消す。e2e の「Clear=Depth はステンシルを消さない」というコメントも合わせて直す
- `EffectStore` はフォルダのファイルをすべてメモリに読む。Ray-MMD 全体は数百 MB なので、ソースだけを先に読み、テクスチャは `File` のまま持つ
- `techniques[0]` を使い、ScriptClass/ScriptOrder を見ていない
- 標準の材質から写したテクスチャの flipY は、写したときの値のまま (今は画像の flipY が後から変わらないので問題ない)

### 第 5 の計画 (ほかの MME エフェクト)
- CullMode NONE で canvas に描くとき、VFACE が逆 (ポストエフェクトがあるときは正しい)。面の向きの uniform を足す
- DestBlend の BOTH*、使わないサンプラーの状態を警告しない、`Draw=Foo`、無限の `Loop`
- WORLDINVERSE が影のパスで 0 の行列
- 文字列でない Subset の注釈が、すべてに当たる
