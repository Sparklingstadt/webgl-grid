## 目的

MME の割り当てまわりの残りを作る。この計画の終わりには、次のことができる。

- MMD と同じく、**アクセサリ**（の代わりの「仮のアクセサリ」）に .fx を当ててポストエフェクトにし、その位置・大きさ（`X`〜`Tr`）を .fx が読める。
- **コントローラー**（`ray_controller.pmx` の代わりの「仮のコントローラー」）・アクセサリの値・.fx の**パラメータ**に、キーフレームを打って動かせる。
- MMD で作った **.emm** を読んで割り当てを戻し、いまの割り当てを .emm に書き出せる。
- `fx/` に置いたエフェクトを**一覧から**読み込める。
- **MCP** から MME の割り当て・値を操作できる。

## 決めたこと

- 4 つとも入れる: .x アクセサリ、.emm の読み書き、キーフレームとパラメータ、`fx/` の一覧と MCP（と、第 4 の計画から回した割り当ての画面の後片付け）。
- **.x は値だけ。** .x の形は読まない・描かない。ray.x と同じ考え方で「仮のアクセサリ」を置き、`X`・`Y`・`Z`・`Rx`・`Ry`・`Rz`・`Si`・`Tr`・表示 を値として持つ。
- **キーフレームは全部に打てる**: 仮のコントローラーの項目・仮のアクセサリの値・.fx のパラメータ。
- 作り方は **「MME の物」をアウトライナーの物の 1 種類にする**。キーフレーム・タイムライン・グラフエディター・取り消し・複製・保存・MCP の `insert_keyframe` を、いまの仕組みのまま使う（MME の欄に専用の仕組みは作らない）。

## 1. MME の物

新しい物の種類 **「MME の物」**（`Obj.mmeObj`）。アウトライナーに出て、選ぶ・名前を変える・複製・消す・保存・取り消し・コレクションに入れる、が今の物と同じ。形はないので、どのエンジンでも描かれず、物を積む動き（積み重ねの高さ・足場）にも入らない。

```ts
// src/core/mme/settings.ts（形は計画で決める。考え方）
interface MmeObjData { kind: 'controller' | 'accessory'; name: string }   // name: 'ray_controller.pmx'・'ray.x' など
```

### 仮のコントローラー

- 名前と項目（`SSAO+` など。0〜1）を持つ。項目は、描いているエフェクトの `CONTROLOBJECT` から集める（第 4 の計画の `Controllers.catalog`）。
- 値は物の **MME チャンネル**（下の 2.）として持つ。
- 第 4 の計画の「場面の値のスライダー」（`MmeScene.controls`）は、これに置き換える。古いプロジェクトの値は、開くときにコントローラーの物に移す。
- MME の欄には、場面にまだない名前を「置く」ボタン付きで並べる（勝手には置かない）。

### 仮のアクセサリ

- 名前と `X`・`Y`・`Z`・`Rx`・`Ry`・`Rz`・`Si`・`Tr` を MME チャンネルとして持つ。既定値は MMD と同じ（`Si` = 1、`Tr` = 1、ほかは 0）。表示（`bool`）は「物を隠しているか」。位置と回転は MMD の座標（第 4 の計画の MMD の単位）。
- **アクセサリに当てた .fx（`Obj.mme` の `Main` の物の割り当て）が、ポストエフェクトになる。** 描く順は、アウトライナーでのアクセサリの並び。
- MME の欄の「ポストエフェクトの一覧」は、アクセサリを並べたものとして見せる（上下に動かす = アクセサリの並びを変える、オン・オフ = 隠す、外す = 割り当てを外す）。
- 第 4 の計画の `MmeScene.posts` は、開くときにアクセサリの物に移す。アクセサリの名前は、ポストエフェクトの .fx のファイル名の拡張子を `.x` にしたもの（`ray.fx` → `ray.x`）。
- `CONTROLOBJECT` の `name="xxx.x"`（アクセサリの項目 `X`〜`Tr`・`XYZ`・`Rxyz`・行列・表示）と、アクセサリに当てた .fx の `(self)` は、このアクセサリの値を読む（第 4 の計画で 0 と警告にしていたもの）。行列は `Si` の拡大と `Rx`〜`Rz` の回転と `X`〜`Z` の位置から作る（MMD のアクセサリと同じ順）。

## 2. パラメータとキーフレーム

### パラメータ

- 対象: .fx の、初期値を持つ uniform の数値（`float`〜`float4`・`int`・`bool`）。セマンティクスの付いたもの（MME が値を入れるもの、`CONTROLOBJECT` を含む）は対象にしない。
- 注釈: `UIName`（名前）、`UIMin`・`UIMax`（範囲。なければ初期値から決める）、`UIWidget = "Color"`（色の部品）、`UIHidden`（出さない）。
- 値は **「.fx を当てた物」と「.fx」の組ごと**。アクセサリのポストエフェクトはそのアクセサリ、モデルに当てた .fx（Main・オフスクリーンのタブ）はそのモデルが持つ。描くたびに、その物の値で uniform を上書きする（EffectInstance は .fx ごとに 1 つのまま）。
- ステージに当てた .fx の値も変えられる（場面の値。キーフレームは打てない）。DefaultEffect だけで決まった物の .fx は初期値のまま。

### MME チャンネル（キーフレーム）

- 物のアニメーション（`core/animation.ts` の `Animation`）に、新しいチャンネルの種類 **`mme`** を足す。物ごとにチャンネルの名前の一覧（`Obj.mmeChannels`）を持ち、番号はその一覧の位置。
  - コントローラーの項目: `SSAO+`
  - アクセサリの値: `Si`
  - パラメータ: `<フォルダの id>/<.fx のパス>:<名前>`（`float3` は `:x`・`:y`・`:z` の 3 チャンネル）
- いまのキーフレームの仕組み（挿入・削除・コピー・貼り付け・移動・補間曲線）、タイムライン、グラフエディター、取り消し、保存、MCP の `insert_keyframe` が効く。

### 画面

- サイドバーに、選んでいる物の **MME の値の欄**: コントローラーは項目のスライダー、アクセサリは `X`〜`Tr`、どちらにも（とモデルにも）「エフェクトのパラメータ」を .fx ごとに。値ごとにキーのボタン（◆。いまの表情の欄と同じ形）。

## 3. .emm の読み書き

- .emm は INI 形式の文字のファイル。`[Info]` に物の番号とファイル（`.pmx`・`.x`）、`[Effect]`（Main）とオフスクリーンの名前の節に `Obj[n] = .fx のパス`・`Obj[n].材質の番号 = …`・`Obj[n].show = false` など。**細かい書式は実装の最初に MME の資料で確かめ、表にする。** 手元に見本の .emm がないので、テスト用の .emm は自作する。
- **読み込み**（MME の欄の「.emm を読む」）:
  - `[Info]` のファイル名と、場面の物の名前（モデルは .pmx のファイル名、アクセサリは名前、ステージは .pmx のファイル名）を照らし合わせる。同じ名前が複数あれば、.emm の番号の順に場面の並びの順で当てる。合わないものは警告にまとめて飛ばす。
  - .emm にある `.x` が場面にないときは、その名前の仮のアクセサリを作る。
  - .fx のパスは、読み込んである .fx フォルダの中で、**パスの後ろの部分がいちばん長く合うもの**（大文字小文字・`\` を吸収）。見つからないものは警告にまとめて、その割り当てだけ飛ばす。
  - 1 回の取り消しで元に戻る（割り当ては物ごとの値。アクセサリを作るのも同じ取り消しに入る。ステージの割り当ては場面の値なので、取り消しの対象にしない）。
- **書き出し**（「.emm を書き出す」）: いまの割り当てを .emm にしてダウンロードさせる。.fx のパスは `フォルダの名前\フォルダの中のパス` の相対パス（.fx のフォルダが並ぶ場所に .emm を置けば MMD で読めるように。README に書く）。物の番号は場面の並び。

## 4. `fx/` の一覧・MCP・画面の後片付け

### `fx/` の一覧

- `models/` の一覧（`mcp/models.ts`・`src/core/models.ts`・`src/engine/io/modelsFolder.ts`・`ModelPicker`）と同じ仕組み。開発サーバー・プレビューと MCP サーバーが `fx/` の一覧とファイルを渡す。場所は環境変数 `WEBGL_GRID_FX_DIR`（テスト用）。
- MME の欄の「読み込む…」に「`fx/` から選ぶ」。選んだフォルダのファイルだけを取ってきて、いまのフォルダの読み込み（`EffectStore.addFolder`）に渡す。一覧を渡すサーバーがないときは出さない。

### MCP のコマンド（`src/engine/remote/commands.ts`）

| コマンド | すること |
|---|---|
| `mme_state` | 設定・フォルダ・タブ・割り当て・アクセサリ・コントローラー・警告 |
| `mme_set` | レンダーエンジン・セルフシャドウなどの設定 |
| `mme_list_fx` | `fx/` のフォルダと .fx の一覧 |
| `mme_load_folder` | `fx/` のフォルダを読み込む |
| `mme_assign` | 物・ステージに、タブ・材質を指定して .fx・非表示・既定 |
| `mme_add_accessory` | 名前と .fx を指定してアクセサリを置く |
| `mme_add_controller` | コントローラーを置く |
| `mme_set_values` | コントローラー・アクセサリ・パラメータの値 |
| `mme_import_emm` / `mme_export_emm` | .emm を読む・書き出す |

キーフレームは、いまの `insert_keyframe` で MME チャンネルも打てるようにする。

### 割り当ての画面の後片付け（第 4 の計画から回した分）

- .fx の選択肢は 1 回だけ作って使い回す。選んでいるものは表示の文字でなく id で照らし合わせる。
- タブのアクセシビリティ（`aria-controls`・`tabpanel`・矢印キー）、既定の欄の `aria-describedby`、同じ名前の物のラベルが重ならないこと、長い名前で横にはみ出さないことのテスト。
- ステージの割り当てに .pmx の名前を持たせ、名前が違うステージには当てない（ステージを差し替えたとき、前の空の .fx が会場に当たらない）。

## エラーの扱い

- .emm で合わなかった物・.fx は、警告にまとめて出す（t() を通す。4 つの辞書）。
- パラメータの値は範囲に収める。
- 古いプロジェクトの移し替え（ポストエフェクト → アクセサリ、スライダーの値 → コントローラー）で合わないものがあれば、警告を出す。

## テスト

1. **単体テスト**: .emm の読み書き（自作の .emm・往復）、パラメータの一覧の作り方（注釈）、MME チャンネルのキーフレームの計算、古いプロジェクトの移し替え、アクセサリの行列、`fx/` の一覧の作り方。
2. **画面のテスト（e2e。自作の .fx。CI で動く）**: アクセサリの `Si` で色が変わる、コントローラーのキーフレームで書き出した動画の最初と最後のコマの色が変わる、パラメータの欄で色が変わる、.emm を読んで割り当てが戻る、`fx/` の一覧から読み込める（`WEBGL_GRID_FX_DIR` に自作のフォルダ）、第 4 の計画の形のプロジェクトを開くと同じ絵。
3. **MCP**: `commands.test.ts` に各コマンド。
4. **手元だけのテスト**（`fx/ray-mmd-1.5.2/` があるとき）: `e2e/ray-mmd-local.spec.ts` を、アクセサリ（`ray.x` に ray.fx）とコントローラーの物で組むように直す。MCP のコマンドだけで同じ構成を組んで書き出すテストを足す。

## 合格の基準

1. 第 4 の計画の Ray-MMD の構成が、アクセサリ（`ray.x` に ray.fx）とコントローラーの物（`ray_controller.pmx`）で組め、コントローラーにキーフレームを打つと、書き出した動画の中で変わる。
2. 自作の .emm（MME の書式）を読むと割り当てが戻り、書き出した .emm を読み直すと同じになる。
3. `fx/` の一覧から Ray-MMD を読み込める（手元だけのテスト）。
4. MCP のコマンドだけで Ray-MMD の構成を組んで書き出せる（手元だけのテスト）。
5. 第 4 の計画で保存したプロジェクトを開くと、同じ絵になる。
6. 標準のエンジンと、これまでのテストは変わらない。

## この計画に入れないもの

- .x の形の読み込みと描画（値だけ）
- `ANIMATEDTEXTURE`・VFACE の直し・D3D のアルファテスト・ほかの MME エフェクト（第 5 の計画）
- ステージのパラメータのキーフレーム（ステージは物でないため）
