# webgl-grid

three.js で描いた無限に続くグリッドの上に、立方体や球などの形・ライト・MMD モデル（.pmx）・ステージを置いて、モーション（.vmd）と曲で踊らせたり、キーフレームでポーズのアニメーションを作ったりできるアプリです。画面は Blender（4.x）のアニメーション作業の画面を手本にしています。

React + TypeScript + Vite で作っています。GitHub Pages での公開は停止中です。

## 動かす

Node.js（20 以降）が必要です。

```bash
npm install
npm run dev
```

表示された http://localhost:5173/ を開きます。`start.command`（Finder でダブルクリック、またはターミナルで `./start.command`）なら、はじめての `npm install` と `npm run build` をしてから http://localhost:4173/ で配り、ブラウザで開きます（ポートがふさがっていれば止まります。止めるのは Ctrl+C）。`npm run build` で `dist/` に書き出せます（相対パスで参照するので、どのフォルダに置いても開けます）。物理演算に使う Ammo.js（`public/libs/`）は大きいので、剛体を持つモデルを初めて読み込んだときに読みます。どこからも取ってこないので、インターネットにつながっていなくても動きます。

### デスクトップ版（Electron）

[Releases](https://github.com/Sparklingstadt/webgl-grid/releases) から、Mac（Apple Silicon: `mac-arm64`、Intel: `mac-x64`。.dmg か .zip）・Windows（`win-x64`・`win-arm64` の .zip。展開して `webgl-grid.exe`）を落として使えます。Apple の開発者 ID で署名・公証していない（アドホック署名だけ）ので、Mac では初めて開くときに「開発元を確認できない」と出ます。一度開こうとしてから「システム設定 > プライバシーとセキュリティ」の「このまま開く」を押してください（ターミナルで `xattr -dr com.apple.quarantine /Applications/webgl-grid.app` としても開けます）。Windows では SmartScreen の「詳細情報 > 実行」を選んでください。

- 中身はブラウザ版と同じで、アプリを 127.0.0.1（17458 番から空いているポート）で配って窓に開きます。設定や自動保存はアプリの中に覚えます。
- models フォルダは「書類/webgl-grid/models」です（メニューの「ファイル > models フォルダを開く」で開けます。環境変数 `WEBGL_GRID_MODELS_DIR` で変えられます）。ここにモデルのフォルダ（.pmx とテクスチャ）・.vmd・.vpd・曲を置くと、ブラウザ版の `models/` と同じように使えます。
- fx フォルダも同じく「書類/webgl-grid/fx」です（メニューの「ファイル > fx フォルダを開く」で開けます。環境変数 `WEBGL_GRID_FX_DIR` で変えられます）。エフェクトの一式ごとのフォルダ（.fx とそれが読むファイル）を置くと、「効果」のタブの「MME 互換」の欄の「fx/ から選ぶ」から読めます（[fx/README.md](fx/README.md)）。
- MCP サーバー（`npm run mcp`）が動いていれば、「ファイル > 外部から操作 (MCP) を受け付ける」でつながります。
- 自分で作るときは `npm run electron`（ビルドして開く）・`npm run electron:build`（Mac の .dmg・.zip と Windows の .zip を `release/` に作る）。Windows のインストーラー（NSIS）は、Apple Silicon の Mac では Rosetta がないと作れないので作っていません。

WebGL2 に対応したブラウザが必要です。URL に `?debug` を付けて開くと、動作確認用にエンジンを `window.engine` としてブラウザのコンソールから触れます（e2e テストもこれを使います）。

## 画面

起動したときは何も置いていません（ビューポートに置き方の案内が出ます）。ただし `models/` に `げのげ式初音ミク.pmx` があれば、まずそれを読み込み、`models/` に .vmd があれば、そのフォルダの .vmd 全部（体・表情・口・カメラ）と曲も付けて再生します（読み込めなければ、`models/` の一覧から選べます）。「追加」（Shift+A）で形やライトを置くか、MMD モデルを読み込んでください。「ファイル > 最初の状態に戻す」も、この何もない場面に戻します。

## 言語

上のバーの右で、画面の言語を **日本語・English・简体中文・繁體中文** から選べます（最初はブラウザの言語。選んだ言語は覚えておきます）。用語は Blender と Cinema 4D の各言語の表示に合わせています。MMD のボーン名・表情名・マテリアル名などのデータと、MCP 向けの説明は訳しません。

- 文言は日本語で書き、その日本語を鍵に `src/i18n/` の辞書から訳を引きます（`t('…')`。`{名前}` は値に置き換え）。辞書に画面の文が全部あるかは、単体テストが確かめます

## 元に戻す・やり直し

- **Ctrl+Z** で元に戻し、**Ctrl+Shift+Z**（Ctrl+Y）でやり直します（Mac は ⌘）。「編集」メニューには、戻す手の名前（移動・色・マテリアル・キーフレームなど）と最近の履歴が出て、押すとその状態まで戻ります。
- 戻せるもの: 物の追加・削除（MMD モデルも。読み直さずに、物理演算・モーションごと戻ります）・移動・回転・色、マテリアル（スロット・値・ノード・名前・新規）、ポーズ・表情・キーフレーム、髪を垂らす、フレーム範囲。
- ドラッグやスライダーを動かしているあいだの変化は、離したときに 1 手にまとめます。視点・いまのフレーム・選択は、Blender と同じく手に数えません。履歴は 64 手まで。「最初の状態に戻す」とプロジェクトを開いたときは、履歴を空にします。

## 自動保存と前回の続き

- 編集すると、3 秒ほどあとにブラウザの中（IndexedDB）へ場面を自動で保存します。ページを隠したとき（タブを切り替える・閉じる）も保存します。中身は参照だけのプロジェクト（.wgpj）と、それが参照するファイル（モデル・テクスチャ・モーション・曲。一度しまったファイルはしまい直さない）です。
- ページを開くたびに別の回として残し、最近の 3 回を持ちます。次に開いたとき、前の回があればビューポートの左下に「前回の続きがあります」と出るので、「開く」で続きから始められます（「ファイル > 前回の続きを開く」からも）。
- 保存はこのブラウザの中だけで、どこにも送りません。ブラウザのサイトデータを消すと消えます。

## 入力の部品

入力の部品は、ブラウザ標準のものではなく、Blender 風のアプリ独自のものです（キーボードと読み上げにも対応しています）。

- **選択肢**: 押すと一覧が開きます。開いていなくても ↑↓ で前後を選べ、開いているときは ↑↓・Home・End・Enter・Esc と、頭文字で探せます。
- **数値の欄**: 左右にドラッグすると値が変わり、両端の ‹ › で 1 段ずつ増減、クリックすると打ち込めます（打ち込み中は ↑↓ で 1 段ずつ、Enter で決定、Esc でやめる）。
- **スライダー**: ドラッグ・矢印キー（Shift で 10 倍）、Enter かダブルクリックで打ち込み。
- **色の欄**: 押すと色選びの窓が開き、彩度・明度の面と色相のバー（矢印キーでも動く）か、16 進で色を決めます（Enter で閉じる）。
- **チェック**: 押すか Space で切り替え。

## 操作

以下の「物」は、形・ライト・読み込んだ PMX モデルのどれにも当てはまります（色を変える操作は形だけ）。

| 操作 | 内容 |
| --- | --- |
| 追加 > 立方体・球・円柱・円錐・カプセル・トーラス・チューブ・円盤・平面・三角錐・正二十面体（Shift+A） | 画面中央の近くに置いて選ぶ（最大32個。8色のうち使われていない色を優先） |
| 追加 > カメラ、テンキー 0 | いまのビューポートの視点（位置・向き・視野角）にカメラを置く（Blender のカメラ）。目印（四角すいの枠）はビューポートだけ。プロパティの「カメラ」のタブで視野角・高さ・傾き、向きは物の回転で変える。置いてあれば、レンダリング（F12・動画）はアウトライナーでいちばん上のカメラ（場面のカメラ）から撮る（VMD のカメラモーションがあればそちら）。テンキー 0 で場面のカメラから見る（自分で動かすと戻る）。位置・回転のキーも打てる。MCP の `add_camera`・`set_camera_object` |
| ファイル > プロジェクトを開く…（Ctrl+Shift+O）/ プロジェクトを保存（Ctrl+S） | いまの場面をまるごと .wgp に保存する・開き直す（下の「プロジェクト」） |
| ファイル > MMD を読み込む…（Ctrl+O） | .pmx とテクスチャ画像をまとめて選ぶと、モデルを置く（ステージの .pmx なら原点に）。.vmd（ダンス・カメラ）、.vpd（ポーズ）、曲も一緒に選べる。テクスチャが見つからなければ、置く前に「テクスチャを探す」窓でフォルダか画像を選べる |
| 起動したとき・ファイル > models フォルダから読み込む… | 起動したときは、`models/` のどこかに `げのげ式初音ミク.pmx` があればまず読み込み、モーションと曲も付けて再生する（モデルのフォルダの中で最初に .vmd があるフォルダ、なければ `models/` で最初に .vmd があるフォルダ（名前の順）の、.vmd 全部と曲。体・表情・口に分かれた .vmd は 1 つの動きにまとめる。元に戻す手には数えない。なければ・読み込めなければ一覧を出す。決まったモデルの名前は `src/core/models.ts` の `DEFAULT_MODEL_FILE`）。プロジェクトの `models/` フォルダ（`models/モデル名/` に .pmx とテクスチャ）のモデルを一覧から選んで、テクスチャ付きで読み込む。`models/` の中の .vmd は「モーション」、.vpd は「ポーズ・表情」から選べる（選んでいるモデルに付ける）。曲（.mp3・.wav など）は「曲」から選んで再生する。`models/` の中身は Git に入らない（[models/README.md](models/README.md)） |
| ファイル > MMD をフォルダごと読み込む… / ファイル・フォルダを画面に落とす | モデルのフォルダごと読み込む（中のテクスチャも）。.wgp / .wgpj を落とすとプロジェクトを開く |
| 物をクリック / タップ | 選ぶ（オレンジの輪郭線）。何もない所をクリックすると選択を解除（Alt+A でも解除） |
| 形をタップ（スマホ） | 選んで、8色のパレットを出す |
| 何もない地面を長押し（スマホ） | 最後に追加した形をその場所に置く（ほかの物と重なる位置なら上に積む） |
| 物をドラッグ（スマホは長押ししてから） | 運ぶ。ほかの物の上まで運ぶとその上に積まれ、上に載っている物も一緒に運ばれる。離すと下に落ちる |
| 物を Shift+ドラッグ / 2本指でひねる（スマホ） | 縦軸まわりに回す（上に載っている物も一緒に回る） |
| クリック / Shift+クリック、A / Alt+A / Ctrl+I、B | 選ぶ（何もない所で解除）/ 選択に足す・外す、すべて選択 / 解除 / 反転、ボックス選択（ドラッグで囲む。Shift で足す、Esc でやめる）。選んでいる物の最後がアクティブ（明るいオレンジ。プロパティで変えるのはこれ）。削除（X）・隠す（H）・複製（Shift+D）は選んでいる物すべて。アウトライナーでは Shift / Ctrl+クリック。ビューポートの「選択」のメニューにも |
| G / R / S（Alt で元に戻す） | 選んでいる物を、マウスで移動 / 回転 / 拡大縮小する（Blender と同じ）。移動は X・Y キーで軸をしぼる（Y は奥行き）。数字を打つと、その値ちょうど（距離・度・倍率）。クリック・Enter で決定、Esc・右クリックでやめる。いくつか選んでいれば、真ん中を中心に回す・広げる。大きさは形と MMD モデル（モデルは物理演算の剛体ごと大きくなり、髪やスカートもそのまま揺れる。ライト・カメラは変えない。オブジェクトのタブ・N パネル・MCP の `set_object` の `scale` でも）。Alt+G・Alt+R・Alt+S で位置（原点へ）・回転・大きさを元に戻す。決めるまでで元に戻すの 1 手。動かしているあいだ Ctrl を押すとスナップ（移動はグリッドの目 1 m、回転は 15°、拡大縮小は 0.1 倍ずつ。Shift も押すと 0.1 m・1°・0.01 倍）。ビューポートの見出しの磁石（Shift+Tab）を入れると、いつもスナップして Ctrl で外れる |
| 右クリック（動かさずに離す） | 押した物を選んで（選んでいなければ）、オブジェクトのメニューを出す: 移動・回転・拡大縮小・複製・名前を変更・隠す・削除・すべて選択・選択を反転・すべて表示（Blender のコンテキストメニュー）。右ドラッグはカメラの操作のまま。Esc で閉じる |
| ライト・カメラのギズモ | ライトかカメラを選ぶと、ビューポートの目印のまわりに輪と取っ手が出る（Blender のライトのパワー・カメラのギズモ）。取っ手を左右にドラッグして、ライトはパワー（サンは強さ。右へ 100 px で 2 倍）、カメラは視野角（1 px で 0.2°）を変える。Shift で細かく、Esc でやめる。取っ手にフォーカスして ←→ でも。元に戻すでは 1 手 |

## MoGraph（Cinema 4D の MoGraph）

Cinema 4D の MoGraph を、組み込みのアドオンで再現しています（どれも最初から有効。アドオンマネージャーで 1 つずつ切れます。切ると働かなくなりますが、付けた設定は覚えていて、有効にし直すと戻ります）。

| アドオン | 中身 |
| --- | --- |
| **Cinema 4D** | クローナー（直線・放射・グリッド）・デフォーマと、MoGraph の登録口（エフェクタ・フィールド・並べ方を、ほかのアドオンが足す）・MoGraph 選択 |
| **MoGraph エフェクタ** | プレーン・ステップ・ランダム・フォーミュラ・タイム・ターゲット・ディレイ・シェーダー・プッシュアパート・ボリューム・継承・サウンド |
| **MoGraph フィールド** | リニア・球・ボックス・円柱・放射・ランダム・ノイズ・タイム |
| **MoGraph 配置** | クローナーの並べ方: ハニカム・オブジェクト |
| **MoGraph 分割** | ボロノイ分割・PolyFX |
| **MoGraph テキスト (MoText)** | 厚みのある文字を、文字・単語・行ごとにエフェクタで動かす |
| **MoGraph スプライン (MoSpline)** | 伸びる曲線 (シンプル・タートル) と、スプラインに並べるクローナー・スプライン・エフェクタ |
| **MoGraph トレーサー** | 動く物・クローン・ボーンの通った跡 (経路) と、いまの位置どうしの連結 |

MoGraph のアドオンは、どれも Cinema 4D アドオンが必要です（有効にすると一緒に有効になり、Cinema 4D を切ると一緒に切れます）。MoExtrude・キャッシュはまだありません。

### クローナー

- 物を選んで、プロパティの「モディファイアー」の「クローナー」にチェックを入れる（か「オブジェクト > クローナーにする / やめる」）と、その物を並べます。元の物の位置と向きが中心で、元の物を動かす・回すと、クローンも一緒に動きます（Cinema 4D でクローナーの子にした状態）。
  - **直線**: 数・1 つごとのずれ（X・Y・Z）・1 つごとの回転
  - **放射**: 数・半径・角度の範囲（一周なら等分）・外を向く
  - **グリッド**: X・Y・Z の数と間隔（横は元の物を真ん中に、縦は地面から上へ）
  - **ハニカム**（MoGraph 配置）: 蜂の巣のように、1 段おきに半分ずらして並べる（床・壁）
  - **オブジェクト**（MoGraph 配置）: ほかの物（MMD モデルも）の頂点・面の中心・表面（ランダム）・中身（ランダム）に並べ、面の向きに合わせられる。その物を動かすとついていく（MMD モデルは動かす前の形）
  - **ばらつき**: 位置・回転のばらつきとシード（同じシードなら同じ並び）
- **MMD モデル**も並べられます。クローンは毎フレーム元のモデルの骨と表情を写すので、モーション・物理演算・手で動かしたボーンごと、全員が同じ動きで踊ります（25 体まで）。
- クローンを押すと元の物が選ばれます。クローンは積み重ねには加わりません（足場は元の物だけ）。
- 「1 つずつの物にする」（Cinema 4D の「現在の状態をオブジェクト化」）: 形のクローンを、1 つずつの物にします（マテリアルは共有。置ける物の数まで）。

### エフェクタ（MoGraph エフェクタ）

クローナー（と分割）のパネルの「エフェクタ」から足します。いくつでも重ね、上から順にかけます（チェックで一時的に外せる）。どれも位置・回転・大きさ（Cinema 4D の「パラメータ」）を、エフェクタの強さに合わせて足します。強さは **フィールド**（効く範囲）と **MoGraph 選択**（効くクローンの番号。`0-4, 7`・`偶数`・`奇数`）で決まります。

- **プレーン**: 全部のクローンを同じだけずらす・回す・大きさを変える
- **ステップ**: 最初のクローンの 0 から最後のクローンの値まで、だんだん強くかける
- **ランダム**: クローンごとに、位置（軸ごと）・回転・大きさをばらつかせる（シードが同じなら同じばらつき）
- **フォーミュラ**: 式で強さを決める（Cinema 4D と同じ書き方。既定は `sin((t*f + id/count*w)*360)`）。変数は `t`（時刻）・`f`（周波数）・`w`（波の数）・`id`（番号）・`count`（数）・`x` `y` `z`（位置）・`rnd`（乱数）。関数は `sin` `cos` `tan`（度）・`abs` `floor` `min` `max` `pow` `sqrt` `clamp` など。式はアプリが自分で読み、JavaScript としては動かさないので、人からもらったプロジェクトに入っていても安全です
- **タイム**: 時刻（秒）に合わせて強くする（回り続ける・伸び続けるなど）
- **ターゲット**: クローンを、決めた場所（地面の X・Z）へ向ける
- **ディレイ**: MMD モデルのクローンを、1 つごとに決めたフレームずつ遅らせて動かす（ウェーブ）。元のモデルの姿勢をフレームごとに覚えて写すので、物理演算ごと遅れます。再生すると（とレンダリングで）効き、別のフレームへ飛んだ直後は、覚えるまで遅れません（300 フレームまで）
- **シェーダー**: ノイズの模様で強さを決める（場所でなめらかに変わる。速さを付けると流れる）
- **プッシュアパート**: 近すぎるクローンどうしを、半径の距離まで押し離す
- **ボリューム**: 選んだ物の中（その物の箱の中）にあるクローンだけに効く
- **継承**: ほかのクローナーのクローンの置き場所・向き・大きさへ、番号ごとに近づける（フィールドで途中まで）
- **サウンド**: 読み込んだ曲の大きさで強さを決める。曲を一度だけ調べ（FFT・16 の帯域）、クローンごとに低い音から高い音の帯を受け持つか、全体の大きさにする。時刻で決まるので、動画のレンダリングでも同じに動く

### フィールド（MoGraph フィールド）

エフェクタの「フィールド」から足し、層を上から重ねます（重ね方: 標準・最大・最小・加算・減算・乗算。不透明度・反転）。フィールドがなければ、エフェクタは全体に効きます。場所を持つフィールドは、物を選んでいるとビューポートに青い枠を出します（レンダリングには写りません）。

- **リニア**: 軸にそって 0 から 1 へ / **球**・**ボックス**・**円柱**: 中で効く（内側の割合までは 1、外へなめらかに 0） / **放射**: 中心のまわりの角度で
- **ランダム**: クローンごとにばらばら / **ノイズ**: 場所でなめらかに変わる（速さで流れる） / **タイム**: 時刻に合わせて 0 から 1 へ

### 分割（MoGraph 分割）

形を選んで、プロパティの「モディファイアー」の「分割」にチェックを入れる（か「オブジェクト > 分割する / やめる」）と、形を破片に分けます。破片はエフェクタ（とフィールド）で動かせます。

- **ボロノイ分割**: 形の中のランダムな点（数・シード・散らばり: 一様・中心に寄せる・外に寄せる）で、破片に分ける。凸な形だけ（トーラス・チューブは PolyFX で）
- **PolyFX**: 面（三角形）ごとの破片にする
- すき間で破片を縮められます。破片は 1 つのメッシュにまとめて描くので、多くても重くなりません（200 個まで）。デフォーマで変えた形も分けます

### MoExtrude（MoGraph MoExtrude）

形を選んで、プロパティの「モディファイアー」の「MoExtrude」にチェックを入れると、形の面（同じ向きでつながった三角形のまとまり）を法線の向きへ押し出します。

- 長さ・段の数（壁を分ける数）・ふたの大きさ（先を細く・太く）を決める。エフェクタ（とフィールド）の大きさで面ごとの長さが変わり、位置で先がずれる
- 元の形は隠す（やめると出す）。デフォーマで変えた形も押し出す。400 面まで。元に戻す・プロジェクト・MCP（`run_command` の `mograph-extrude.set`）

### MoGraph キャッシュ

クローナーにしている物を選んで、プロパティの「モディファイアー」の「MoGraph キャッシュ」で「焼き付ける」を押すと、開始〜終了の各フレームのクローンの置き場所を覚えます（Cinema 4D の MoGraph キャッシュタグ）。

- 焼き付けたあとは、再生・レンダリング・時刻を飛ぶときも計算せずにそれを使う（重いエフェクタでも軽く、いつも同じ結果）。範囲の外は端のフレーム
- 設定を変えても、消すまではキャッシュを使う。クローンの数が変わったら使わない（焼き付け直す）
- 元に戻す・プロジェクトにも残る。MCP（`run_command` の `mograph-cache.bake`・`mograph-cache.clear`）

### MoSpline（MoGraph スプライン）

「追加 > MoSpline」で置くか、形を選んで「MoSpline にする」と、伸びる曲線を管にして置きます（Cinema 4D の MoSpline とスイープ）。

- **シンプル**: 長さ・分割数・曲がり・ねじれで、くるくる巻いた線
- **タートル**: L-システム（前提と規則を書き換え、亀が歩いた跡）。見本: 木・草・立体の木・コッホ曲線。`F` 進む・`+` `-` 曲がる・`&` `^` 上下・`\` `/` ひねる・`[` `]` 枝
- 始め・終わり（見せる範囲）・**成長**（時刻に合わせて伸びる）・太さ（始めと先。0 で線）
- クローナーの並べ方 **スプライン**（MoSpline・トレーサーの曲線にそって並べる）と、**スプライン・エフェクタ**（クローンを曲線の上へ）も足します

### トレーサー（MoGraph トレーサー）

物を選んで「トレーサー」の「跡を残す」にチェックを入れると、通った跡を線か管にして残します（レンダリングにも写ります）。

- **経路**: フレームごとの位置を覚えて、決めたフレーム数だけ跡を残す（再生・動画のレンダリングで伸びる。別のフレームへ飛ぶと取り直す）。古い方ほど細い
- **連結**: いまの位置どうしを順につなぐ（閉じることもできる）
- 跡を取るもの: 物（クローナーならクローンごと・MoText なら文字ごと）か、MMD モデルの**ボーン**（名前で。例: `右手首、左手首`）
- 跡はスプラインとして、スプラインに並べるクローナーなどでも使えます

### テキスト（MoGraph テキスト・MoText）

「追加 > テキスト (MoText)」で置くか、形を選んでプロパティの「オブジェクト」の「テキスト (MoText)」にチェックを入れると、厚みのある文字を立てて置きます（前は +Z）。

- 文字（改行で複数行）・フォント（ゴシック・明朝・等幅・手書き風か、フォントの名前）・太字・大きさ・厚み・面取り・字間・行間・揃え（左・中央・右）
- エフェクタ（とフィールド）を、**文字ごと**・**単語ごと**・**行ごと**・**全体**のどれにかけるかを選べます（Cinema 4D の MoText の「文字」「単語」「行」「全体」）
- 文字の形は、このパソコンのフォントで文字を描き、その輪郭をなぞって作ります（日本語もどの文字も使え、フォントのファイルは要りません。ほかのパソコンでは、入っているフォントによって形が少し変わります）
- 積み重ねの足場と高さは、文字の大きさになります

元に戻す・プロジェクト・自動保存・MCP（`set_cloner`・`bake_cloner`・`set_deformers`・`set_fracture`・`set_motext`。それぞれアドオンの命令 `cinema4d.set_cloner` などを呼ぶ）に対応しています。前の版のプロジェクトのクローナー・デフォーマ・エフェクタもそのまま開けます。

## デフォーマ（Cinema 4D のデフォーマ）

- 物を選んで、プロパティの「モディファイアー」の「デフォーマ」から足します。いくつでも重ね、上から順にかけます（チェックで一時的に外せる）。物の大きさの範囲で、選んだ軸（Y (縦)・X・Z）にそってかけます。
  - **ベンド**: 底から上へ、円弧にそって曲げる（角度・向き）
  - **ツイスト**: 上ほど軸まわりにねじる（角度）
  - **テーパー**: 上を細く（マイナス）・太く（プラス）する
  - **バルジ**: まん中をふくらませる（マイナスでくびれる）
- 形の頂点を動かした写しを作って差し替えるので、影・輪郭線・クリックの当たり判定・クローナーのクローンも、変形した形のままです（法線も変形に合わせて回します）。MMD モデルは、ボーンで動かす前の形にかけます（ミクで 0.06 秒ほど）。
- 元に戻す・プロジェクト・自動保存・MCP（`set_deformers`）に対応しています。積み重ねの足場の大きさは、変形する前のままです。

## シーン（空・床・太陽）

プロパティの「シーン」（Cinema 4D の空・床・太陽、Blender のワールド）で、場面全体の見た目を変えます。ビューポートにも、レンダリングした画像・動画にも写ります。元に戻す・プロジェクト・自動保存・MCP（`set_scene`）に対応しています。

- **空**: ビューポートの灰色（いつもの見た目）・単色・グラデーション（地平線の色から真上の色へ。カメラを回すと空も回る）
- **床**: 果てしなく広い床（色・粗さ）。影は床が受けます
- **太陽**: 明るさ・色・方位・高さ・影を落とすか
- **部屋の光**: まわりから全体を照らす、やわらかい光（環境光）の明るさ

### ライト（Blender のライト）

- 「追加 > ライト」から、Blender と同じ **ポイント**・**サン**・**スポット**・**エリア** を置けます。ほかの物と同じくクリックで選び、ドラッグで運び、Shift+ドラッグで向きを変えます。
- 設定も Blender と同じ名前と単位です: カラー、パワー（W。サンは強さ W/m²）、半径（ポイント・スポット）、角度（サン）、スポットサイズ（円すい全体の角度）とブレンド、エリアの形状（正方形・長方形）とサイズ、影。明るさは Blender（Cycles）と同じ定義で three.js に直します（ポイント・スポットは W ÷ 4π、エリアは W ÷（π × 面積）、サンはそのまま）。
- ほかに、高さ（積み重ねには加わりません）・傾き（真下から物の向きの前へ）・カスタム距離（0 で果てしなく）を決められます。サンは置いた場所によらず、場面全体を同じ向きから照らします。エリアは影を落とせず、形は正方形と長方形だけです（three.js の面光源は四角形のみ）。
- 前の版のプロジェクト（点光源・スポットライト・エリアライトと明るさ）は、開くと同じ明るさのパワーに直します。
- ビューポートには目印（と床までの線）を出し、レンダリングでは目印を描かずに光だけが写ります。元に戻す・プロジェクト・自動保存・MCP（`add_light`・`set_light`）に対応しています。

## キーフレームとタイムライン

- 時刻はタイムラインが持ち、モーション（.vmd）・カメラモーション・曲・キーフレームをそれに合わせます。再生すると、終了フレームまで行ったら開始フレームに戻って繰り返します（Blender と同じ）。フレームは MMD と同じ 1 秒 30 フレームです。
- モーションや曲を読み込むと、終了フレームをその長さに合わせ、最初から再生します。ダンス・カメラ・曲はずれないように同じ時刻にそろえます。曲があるときは、曲の再生位置に合わせて進めます。
- キーフレームは、ボーン 1 本・表情 1 つの**チャンネルごと**に持ちます（Blender・MMD と同じ）。
  - **I**（「◆ キー挿入」）: 手で動かしたボーンと 0 でない表情（とすでにキーのあるチャンネル）に、いまのフレームのキーを打ちます。何も動かしていなければ、プロパティの「ボーン」で選んでいるボーンに打ちます。
  - 形・ライトを選んで **I** を押すと、位置 X・位置 Z・回転・大きさ（形だけ）にキーを打ちます（選んでいる物すべて。Blender の位置・回転・拡大縮小のキー）。あいだのフレームは補間して動き、タイムラインの行・「チャンネル」の行・元に戻す・プロジェクト・MCP の `insert_keyframe` にも出ます。キーのある値は再生で変わるので、元に戻すの手には数えません
  - 「ボーン」の「◆ このボーン」: 選んでいるボーンだけに打ちます。ほかのボーンのキーとは別のフレームに打てます。
  - 新しいチャンネルは、それより前にキーがあれば、最初のキーのフレームの 0（最初の姿勢）からつなぎます（MMD と同じ）。
  - キーのあいだは、補間曲線にそって、回転を球面線形補間・位置と表情を線形補間でつなぎます。キーのあるボーン・表情は、フレームを動かすとキーの値に戻ります（キーのないボーンは、手で動かした値のまま）。
- **補間曲線**: 「ボーン」の「補間曲線」で、いまのフレームのキーへの、前のキーからの進み方を変えます（MMD の補間曲線と同じく、行き先のキーに付きます）。2 つの点をドラッグするか矢印キーで動かすか、形（直線・なめらか・ゆっくり始まる・ゆっくり終わる）を選びます。1 本の曲線を回転と位置の両方に使います（MMD の X・Y・Z・回転の 4 本には分けていません）。表情のキーは直線でつなぎます（MMD と同じ）。
- タイムラインの「▸ チャンネル」で、モデルの行の下にボーン・表情ごとの行を出します（行が多いときは、左端の名前の上でホイールすると上下に動きます）。チャンネルの ◆ を押すと、そのボーンを選んでそのフレームへ移るので、すぐ補間曲線を変えられます。◆ の選択・ドラッグ・削除は、フレームごとに全チャンネルまとめて行います。
- 前の版で保存したプロジェクト（フレームごとにポーズ全体を記録していたもの）は、開くときにチャンネルごとのキー（直線）に変換します。
- モーションのあるモデルでは、手で動かしたボーンとキーフレームがモーションより優先されます。

## ポーズモード（ボーン・IK・FK・関節をビューポートで動かす）

MMD モデルを選んで、ビューポートの見出しの「ポーズモード」にする（か **Tab**）と、Blender のポーズモードのようにボーンを直接動かせます。

- 関節を点・親子を線でモデルに重ねて出します（**IK** はオレンジのひし形・移動できるボーンは緑・回すだけは青・選んでいるボーンは白）。物理演算で動くボーン（髪・スカートなど）は出しません
- 関節をクリックするとボーンを選び、ギズモで **回す（R・FK）**・**動かす（G・IK のターゲットやセンターなど）**。**Alt+R / Alt+G** で回転・位置を最初に戻す。**I** で選んでいるボーンにキーを打つ
- 動かした値はプロパティの「ボーン」と同じ（元に戻す・キーフレーム・.vpd もそのまま）。ポーズモードのあいだは、物を選び直したり消したりしません
- プロパティの「ボーン」の **IK** で、IK ごとにオン・オフ（オフにすると、足などを FK で直接回せる。モーションの再生でも切ったまま。元に戻す・プロジェクトにも残る）
- 「オブジェクト」の「物理演算」の **剛体と関節を表示** で、物理演算の剛体（赤: ボーン追従・緑: 物理・青: 物理 + 位置合わせ）と関節（黄）を重ねて表示（レンダリングには写りません）

## MMD モデルとモーション

- モデルの `.pmx` と、モデルが使うテクスチャ画像（`.png` `.bmp` `.tga` `.spa` `.sph` など）を**まとめて**選んでください。テクスチャがサブフォルダにある場合も、画像ファイルを一緒に選べばファイル名で対応づけます。見つからないテクスチャは画面上部に表示します。
- モデルは MMD の 1 単位を 0.1 として置きます（標準的な身長 20 のモデルが立方体 2 個分の高さ）。どのモデルも同じ倍率なので、人物とステージの大きさの関係は MMD と同じです。
- **ステージ**: 横幅か奥行きが 40（MMD の単位）を超えるか、名前に「ステージ」「stage」「舞台」を含む .pmx は、ステージとして原点に置きます。1 つだけで、掴んだり積んだりはできません。ステージがあるあいだは地面のグリッドを隠します。
- 選んだファイルはブラウザの中だけで読み込み、どこにも送信しません。ページを再読み込みすると消えます。
- MMD の輪郭線を表示します。物理演算（髪やスカートの揺れ）も動き、運ぶと髪がなびき、落ちるとふわっと浮き、回すと振り出されます。
- **髪を重力で垂らす**: モデルによっては、髪の節ごとに何ともぶつからない剛体を固定の関節で付けて（錘）、重力の中でもモデルの作者が作った髪の形を保っています（MMD でも同じ形になります）。プロパティの「物理演算」の「髪を重力で垂らす」をオンにすると、その錘を外して、髪を重力でまっすぐ垂らします。オフで元の形に戻ります。錘は、頭のボーン（「頭」）に付いた剛体からぶら下がる鎖の中だけで探すので、胸などほかの部分の錘はそのままです。このスイッチは、髪に錘のあるモデルでだけ出ます。
- モーション（.vmd）は、モデルと一緒に選ぶとそのモデルで、.vmd だけを選ぶと置いてあるモデル全員で再生します。骨と表情の動き、足の IK、連動する骨を計算します。カメラモーションは、ステージがあればステージの原点、なければ最初のモデルの向き・場所に合わせます。自分でカメラを動かすと、カメラモーションは止まり、その視点から手動の操作に切り替わります。
- ブラウザに曲の自動再生を止められたときは、画面をタップするか ▶ を押すと再生します。
- 表情（モーフ）はプロパティの「表情」で、.pmx の分類どおり「眉・目・口・その他」に分けて動かせます。ボーンは「ボーン」で、.pmx の表示枠ごとのリストから選び、回転（−180〜180°）と、移動できるボーンは位置も変えられます。足の IK を動かすと、つながった骨がついてきます。
- **材質**: 読み込んだ MMD の材質は、すべてプリンシプル BSDF のマテリアルに変換します（下の「マテリアル」）。テクスチャは画像テクスチャのノードに、色が白でなければ乗算のミックスで掛け合わせ、半透明はアルファに、反射の強さは粗さに、反射色はスペキュラー IOR レベルにします。輪郭線・両面表示・半透明はマテリアルの設定に移します。トゥーン・スフィアマップは使わないので、MMD のトゥーン調ではなく写実的な見た目になります。
- ポーズは MMD のポーズファイル（.vpd、Shift-JIS・左手系）として保存・読み込みできます。手で動かしたボーンといまの表情を保存します。MMD で保存した .vpd も読めます。
- モーションで体が動いても、掴む判定は読み込んだときの姿勢のままです。
- モデルの利用規約（再配布の禁止など）は、それぞれのモデルの readme に従ってください。このリポジトリでは `.pmx` と `げのげ式初音ミク/` を `.gitignore` で除外しています。

## マテリアル（Blender と同じ仕組み）

- **マテリアル** は物とは別のデータで、名前を持ち、複数の物で共有できます。物はマテリアルスロットを持ち、スロットにマテリアルを入れます（立方体などの形は 1 つ、MMD モデルは材質の数だけ）。
- プロパティの「マテリアル」（Blender のマテリアルプロパティ）:
  - スロットの一覧から選び、スロットに入れるマテリアルを選ぶ（ほかの物のマテリアルを選ぶと共有になり、使っている数が表示される）。名前の変更、「新規」（新しいマテリアル）、「複製」（今のマテリアルをコピーして入れ替える）、「外す」。名前が重なると Blender と同じく「.001」などが付きます。
  - **サーフェス**: マテリアル出力につながっているプリンシプル BSDF の入力（ベースカラー・メタリック・粗さ・IOR・アルファ・スペキュラー IOR レベル・伝播・コート・シーン・放射）。ほかのノードがつながっている入力は、その相手の名前を表示します。
  - **設定**: ブレンドモード（不透明・アルファブレンド・アルファクリップ）、裏面を表示しない。
  - **輪郭線 (MMD)**: 輪郭線を付けるか・色・太さ。
  - **書き出し**（MMD モデル）: マテリアルの色・アルファ・粗さ・輪郭線を .pmx の材質に書き戻した `<名前>_edited.pmx` を書き出します。ほかの部分（ボーン・表情・剛体など）は元の .pmx のまま、バイト単位で変えません。MMD で表せないつなぎ方の入力は元の値のままです。テクスチャを読めるよう、元の .pmx と同じフォルダに置いてください。書き出したファイルの扱いは、モデルの利用規約に従ってください。
- **シェーダーエディター**（下の領域を切り替える）: 選んでいる物の、選んでいるスロットのマテリアルのノードを、線でつないで編集します。ノードは「プリンシプル BSDF」「マテリアル出力」「画像テクスチャ」（読み込んだテクスチャや、開いた画像ファイル）「RGB」「値」「ミックス (カラー)」（ミックス・乗算・加算・減算・スクリーン・比較）「数式」（加算・減算・乗算・除算・べき乗・最小・最大）「ノーマルマップ」。色と値は互いに変換してつなげます（Blender と同じ）。シェーダーはシェーダーの入力にだけつなげ、輪になるつなぎ方はできません。
- 値を変えるだけならシェーダーを作り直さないので、スライダーを動かすとすぐに変わります。つなぎ方を変えたときは、three.js の材質のシェーダーを作り直します。
- マテリアルはプロジェクト（.wgp）に保存できます。MMD モデルは .pmx にも書き出せます。

## レンダリング（画像・動画の書き出し）

- 「レンダー > 画像をレンダリング」（F12）: いまのフレームを、いまの視点から出力の解像度で描き、「レンダー結果」に出します。「画像を保存」で `<名前>_<フレーム番号 4 桁>.png` を保存します（Esc で閉じる）。
- 「レンダー > アニメーションをレンダリング」（Ctrl+F12）: タイムラインの開始〜終了フレーム（両端を含む）を動画にして `<名前>.mp4`（または `.webm`）を保存します。名前はプロジェクトの名前、なければ選んでいるモデルの名前です。
  - 再生と同じように 1 フレーム（1/30 秒）ずつ進めて描き（物理演算も同じ間隔で進む）、ブラウザの WebCodecs で圧縮します（[mediabunny](https://mediabunny.dev/) で MP4 / WebM にまとめる）。処理が重くてもコマ落ちせず、画面の速さより速く作れます（フル HD で 90 フレームが約 1.5 秒）。
  - 曲を読み込んでいれば、同じ範囲の曲を入れます（「出力」で外せます）。レンダリング中は進み具合が出て、Esc か「キャンセル」で止められます。
- プロパティの「出力」: 出力のプリセット（YouTube・4K・ショート動画・SNS・正方形・WebM。いまの設定を自分のプリセットとしてブラウザに保存・削除できる）、解像度（フル HD・HD・4K・縦長・正方形のプリセットか、16〜4096 の偶数）、レンダー範囲（Ctrl+B）、モーションブラー（シャッター・サンプル数。動いている物を、シャッターが開いているあいだの動きでぼかす。画像・動画の両方）、フレーム範囲、動画の形式（MPEG-4 (H.264) / WebM (VP9)）と画質、曲を入れるか。設定はプロジェクトに保存されます（自分のプリセットはブラウザに）。
- 描くのはレンダリング用の絵です: 背景はビューポートの灰色で塗り、地面のグリッドと選択の輪郭線は描きません（影と効果は描きます）。
- **出力の枠**: ビューポートに、出力の縦横比の枠（Blender のカメラの枠）を重ねて出し、枠の外を少し暗くします。書き出されるのは、この枠の中に見えているものです（縦横比が違っても、ビューポートで見えない所が写り込むことはありません）。「ビュー > 出力の範囲を隠す / 表示」で切り替えます。

## アドオン（Blender のアドオン）

アプリに機能を足す JavaScript のモジュールです。足したメニュー・パネル・命令は、切ると全部外れます。

**アドオンマネージャー**（「編集 > アドオンマネージャー…」・Ctrl+,）で管理します。

- チェックで有効にする・切る（有効にしたものは、次に開いたときも有効。最初から有効のものも、切れば切ったまま）
- 名前・説明で探す、表示（すべて・有効・切ってある・組み込み・インストールしたもの・エラーのあるもの）とカテゴリで絞り込む
- ▸ で詳しいこと（説明・id・作者）と、足しているもの（メニュー・パネル・MCP の命令・物ごとの値・場面の値）を見る
- 「ファイルからインストール…」か、.js を窓に落としてインストールする（同じ id なら入れ替え）。インストールしたものは、コードを保存する・消すこともできる

- **組み込みのアドオン**: **Cinema 4D** と **MoGraph**（エフェクタ・フィールド・配置・分割。上の「MoGraph」）は最初から有効。ほかは最初は切ってあります: **ターンテーブル**（再生中とアニメーションのレンダリング中にカメラを回す。設定は「シーン」）、**ふわふわ**（物をタイムラインに合わせて上下に揺らす。「オブジェクト > ふわふわさせる」）、**ランダムに散らす**（選んだ形をまわりにランダムに置く。「オブジェクト」のメニュー）。
- **インストール**: 「ファイルからインストール…」で .js を選ぶと、ブラウザの中にしまって有効にします（同じ id なら入れ替え）。例は [examples/addons/hello.js](examples/addons/hello.js)。アドオンはアプリのすべてを操作できるので、信頼できるものだけを入れてください。
- **保存**: アドオンが足した値（物ごと・場面）はプロジェクトに入り、元に戻すこともできます。そのアドオンを切った状態でプロジェクトを開くと「アドオン … のデータがあります」と知らせます。
- **MCP**: `list_addons`・`set_addon` で有効にし、`list_commands` で命令を確かめて `run_command`（名前は `アドオンの id.命令`）で使います。

### アドオンの書き方

`id`（英小文字で始まる英小文字・数字・`-`・`_`）・`name`・`register(api)` を持つオブジェクトを `export default` します（`version`・`author`・`category`・`description` は一覧に出ます。`requires` に必要なアドオンの id を並べると、有効にするとき一緒に有効にし、そのアドオンを切ると一緒に切ります）。`register` が関数を返すと、切るときに呼びます。three.js は import せずに `api.THREE` を使います（アプリと同じもの）。

```js
export default {
  id: 'hello', name: 'ハロー', version: '1.0.0', category: '例',
  register(api) {
    const glow = api.addObjectData({ key: 'glow', label: '光らせる' });           // 物ごとの値 (保存・元に戻す)
    api.addMenuItem({ menu: 'object', label: '光らせる', run: () => glow.set(api.engine.selection.current, true) });
    api.addPanel({ title: 'ハロー', tab: 'ハロー', props: () => [{ type: 'text', text: 'こんにちは' }] });
    api.addCommand('greet', { description: 'あいさつ', run: p => `こんにちは、${p.name}` }); // MCP: run_command "hello.greet"
  },
};
```

| `api` の窓口 | 内容 |
| --- | --- |
| `engine`・`THREE` | アプリの全部（`engine.world`・`selection`・`clock`・`camera` など）と three.js |
| `addMenuItem({ menu, label, run, enabled? })` | メニュー（`file`・`edit`・`render`・`view`・`add`・`object`）の最後に項目を足す |
| `addPanel({ title, tab?, poll?, props?, draw? })` | プロパティにパネルを足す。`tab` は組み込みのタブ（`object`（既定）・`modifier`（モディファイアー）・`physics`（物理演算）・`light`（ライト）・`material`・`morph`・`bone`・`scene`・`fx`・`output`）か、新しいタブの名前。`props` はアプリの部品で描く設定の一覧（`number`（`min`・`max` があればスライダー）・`boolean`・`select`・`color`・`button`・`text`）、`draw(el)` は自分で要素を作る |
| `addObjectData({ key, label, apply?, normalize? })` | 物ごとの値。返り値の `get(obj)`・`set(obj, value)` で読み書きする（`null` でなし） |
| `addSceneData({ key, label, default, history?, apply?, normalize? })` | 場面の値。返り値の `get()`・`set(value)` で読み書きする。「最初の状態に戻す」で `default` に戻る |
| `require(id)`・`expose(value)` | 必要なアドオン（モジュールの `requires`）が `expose` した窓口を受け取る。例: MoGraph エフェクタは、Cinema 4D アドオンの `addEffector` でエフェクタを登録する |
| `addCommand(name, { description?, params?, run })` | MCP の命令（`run_command` で `アドオンの id.name`） |
| `onFrame(update, active?)`・`onBeforeRender(fn)` | 毎フレームの処理（`active` のあいだ）・描く前の処理（物の位置を決めたあと。レンダリングでも呼ぶ） |
| `toast(text)`・`refresh()`・`requestDraw()` | お知らせ・パネルの描き直し・ビューポートの描き直し |

## 外部から操作（MCP）

Claude などの MCP クライアントから、ブラウザで開いている webgl-grid を操作できます（画面にもそのまま反映されます）。

```
MCP クライアント ⇄ (stdio) ⇄ MCP サーバー (mcp/server.ts) ⇄ (WebSocket, 127.0.0.1:7457) ⇄ ブラウザのページ
```

- 使い方:
  1. `npm run build`（MCP サーバーが `dist/` を `http://localhost:7458/` で配ります）
  2. MCP クライアントにサーバーを登録します。Claude Code では、このリポジトリを開くと `.mcp.json` の `webgl-grid` が使えます。ほかのクライアントでは、コマンド `node`、引数 `<このリポジトリ>/mcp/server.ts` を登録します（Node.js 22.18 以上。TypeScript をそのまま動かします）。手で起動するときは `npm run mcp`。
  3. ツール `open_app` で、いつものブラウザにアプリが開いてつながります。`npm run dev` で開いたページなら、URL に `?mcp` を付けるか「ファイル > 外部から操作 (MCP) を受け付ける」を選びます。つながると上のバーに「MCP 接続中」と出ます。
  - MCP サーバーが動いていないときは「MCP 待機中」になり、1・2・4 秒おいて 3 回までつなぎ直します（サーバーが止まって切れたときも同じ）。それでもつながらなければやめてお知らせを出すので、サーバーを起動してからもう一度「受け付ける」を選んでください。
  - 待っているあいだ、ブラウザのコンソールにエラーは出ません。ブラウザはつながらなかった WebSocket を必ずエラーとして出すので、先にページを配っているサーバー（`npm run dev`・`npm run preview`・MCP サーバー）に、MCP サーバーが動いているかを `/__webgl-grid-mcp` で問い合わせ、動いているときだけつなぎます。
- ツール:

| 分類 | ツール |
| --- | --- |
| つながり | `app_status`、`open_app` |
| 場面を見る | `get_state`（物の一覧と id・位置・マテリアル、タイムライン、視点、効果、出力）、`screenshot`（ビューポートの画像） |
| 物 | `add_shape`、`select`、`set_object`（位置・向き・色）、`delete_object`、`reset_scene`、`set_cloner`・`bake_cloner`（クローナー）、`set_deformers`（デフォーマ）、`set_fracture`（分割）、`set_motext`（MoText。この 5 つは MoGraph のアドオンの命令）。MoSpline・トレーサーは `run_command`（`mograph-spline.set`・`mograph-tracer.set`） |
| ファイル | `load_files`（手元のパスの .pmx・.vmd・.vpd・曲。.pmx を渡すと同じフォルダのテクスチャも送る） |
| アニメーション | `timeline`（フレーム・範囲・再生）、`insert_keyframe`、`delete_keyframe`、`list_bones`、`set_bone`、`reset_pose`、`list_morphs`、`set_morph`、`set_hair_hang` |
| 見た目 | `set_camera`、`list_materials`、`set_material`（プリンシプル BSDF の値・設定・輪郭線・名前）、`set_effect`、`set_scene`（空・床・太陽）、`add_light`・`set_light`（ライト） |
| MME 互換 | `mme_state`（設定・フォルダ・割り当て・アクセサリ・コントローラー・パラメータ・警告）、`mme_set`（標準 / MME のエンジン・影）、`mme_list_fx`・`mme_load_folder`（`fx/` のフォルダの一覧と読み込み）、`mme_assign`（物・ステージ・材質のタブごとの .fx。`hide`・外す）、`mme_add_accessory`・`mme_add_controller`、`mme_set_values`（コントローラーの項目・アクセサリの X〜Tr・.fx のパラメータ）、`mme_import_emm`・`mme_export_emm`（.emm）。MME の値のキーは `insert_keyframe` の `channels` |
| アドオン | `list_addons`、`set_addon`（有効にする・切る）、`list_commands`・`run_command`（アドオンが足した命令） |
| 書き出し | `set_output`、`render_image`（画像を返し、パスに PNG を保存）、`render_animation`（動画をパスに保存）、`save_project`（.wgp か、参照だけの .wgpj）、`open_project`（.wgpj は参照しているファイルを手元から探して送る） |

- 安全のため、WebSocket は 127.0.0.1 だけで待ち、localhost・127.0.0.1 から開いたページのつながりだけを受け付けます（ほかのサイトからは操作できません）。ファイルを読み書きするのは MCP サーバーで、クライアントが渡したパスだけです。
- ポートは環境変数 `WEBGL_GRID_MCP_PORT`（WebSocket、既定 7457）と `WEBGL_GRID_APP_PORT`（アプリを配る、既定 7458）で変えられます。ページは `?mcp=<ポート>` で合わせます。

## プロジェクト（.wgp / .wgpj）

- 「ファイル > プロジェクトを保存」（Ctrl+S）で、いまの場面をまるごと 1 つのファイル（`<名前>.wgp`）に保存します。「プロジェクトを開く…」（Ctrl+Shift+O）で開くと、同じ場面に戻ります（いまの場面は閉じます）。
- 保存するもの: 置いた物（形・MMD モデル・ステージ）と、その位置・向き・積み重ね、マテリアル（使っているものだけ。ノードツリー・設定・輪郭線）とスロット、ポーズ・表情・キーフレーム、「髪を重力で垂らす」、ダンスとカメラのモーション、曲、視点、タイムライン（開始・終了・いまのフレーム）、選んでいる物。
- 中身は ZIP で、`project.json`（場面の状態）と、読み込んだファイルそのもの（`assets/`。.pmx と実際に使ったテクスチャ・.vmd・曲・開いた画像）が入っています。プロジェクトだけで開き直せますが、**モデルやモーション、曲のファイルがそのまま入る**ので、人に渡すときは、それぞれの利用規約（再配布の禁止など）に従ってください。リポジトリには `*.wgp` を入れないよう `.gitignore` に入れてあります。
- **ファイルは参照だけで保存（.wgpj）**: 「ファイル > ファイルは参照だけで保存 (.wgpj)」（Ctrl+Alt+S）では、モデル・テクスチャ・モーション・曲などのファイルを入れず、名前と大きさ（分かれば元の場所）だけを書いた小さな JSON を保存します。場面の状態は .wgp と同じです。
  - 開くと、同じページで読み込んだことのあるファイルはそのまま使います。見つからないファイルがあれば一覧を出すので、ファイルが入っているフォルダ（サブフォルダも探します）かファイルそのものを選んでください。名前と大きさで対応づけます。「見つかったものだけで開く」「やめる」も選べます。
  - ブラウザはファイルの置き場所（パス）を知ることができないので、ページで読み込んだファイルは名前と大きさだけを記録します。MCP（`load_files`）で読み込んだファイルは元の場所と、プロジェクトから見た場所も記録するので、MCP の `open_project` で開くと自動で読み込みます。
  - .wgpj にはモデルなどが入らないので、人に渡すときは元のファイルを別に用意してもらう必要があります。

## 効果（MME 風）

MME（MikuMikuEffect）の .fx は DirectX 用の HLSL で書かれていて、標準のレンダーエンジンではそのまま動かせません（.fx そのものを動かすには、下の「MME 互換モード」にします）。標準では、よく使われる MME に近い効果を組み込みで用意しています。プロパティの「効果」で、パネルの見出しのチェックでオン・オフ、スライダーで強さを変えます。オフの効果のスライダーを動かすと、その効果がオンになります。設定はブラウザに保存されます。

| 効果 | 近い MME | 内容 | スライダー |
| --- | --- | --- | --- |
| 光る | AutoLuminous | ごく明るい部分だけを光らせてにじませる | 強さ（0〜2、初期値 0.7） |
| ふんわり | Diffusion | 画面全体に弱い光のにじみをかける | 強さ（0〜1、初期値 0.2） |
| 被写界深度 | DOF 系 | 注視点にピントを合わせ、それ以外をぼかす | ぼけの大きさ（0〜3 倍、初期値 1 倍） |
| 影の濃さ | SSAO 系 | 物の接する所や隙間を暗くする（GTAO。縦横半分の解像度で計算して重ねるので、見た目はほぼそのままで軽い） | 濃さ（0〜2、初期値 1） |
| 色調 | 色調補正系 | 画面に出す直前に色を整える | 色温度（−1〜1）・彩度（0〜2）・明度（0〜2） |

効果をオンにすると描画が重くなります。スマホでは特に「被写界深度」と「影の濃さ」が重くなりやすいです。

### MME 互換モード（作っている途中）

MME の .fx そのものを動かすモードです。.fx を WebGL2 の GLSL ES 3.00 に変換するコンパイラ（`src/core/fx/`。入口は `compileEffect`）と、その出力を MME の決まりどおりに描く実行部（`src/core/mme/`・`src/engine/mme/`）があります。上の表の組み込みの効果は、これとは別の、いままでどおりの仕組みです。

**使い方**

1. プロパティの「出力」のタブで「レンダーエンジン」を「MME 互換」にします（初期値は「標準」。設定はプロジェクトに保存されます）。下に、セルフシャドウ（オン・オフ、影の距離）と地面の影（オン・オフ）の欄が出ます。影の距離（0〜9999）は MMD のセルフシャドウの影の距離と同じ向きで、大きいほど影の落ちる範囲が狭く、くっきりします（初期値の 8875 で標準のエンジンと同じ範囲）。ビューポートの「レンダー」表示と書き出し（PNG・動画）が MME 互換で描かれます（ワイヤーフレーム・ソリッド・マテリアル表示は、いままでどおりです）。何も読み込んでいなくても、MMD モデルは同梱の `default.fx`（MMD の標準の見た目: トゥーン・スフィア・輪郭線・地面の影・セルフシャドウ）で描かれます。
2. 「効果」のタブに「MME 互換」の欄が出ます。.fx が入っている**フォルダ**を選ぶか、ここに落とします（.fx が 2 つ以上あれば、どれを使うか選ばせます。`#include` やテクスチャは、そのフォルダの中から探します。同じ名前のフォルダは 1 つにまとめ、読み直して中身が変わっていればコンパイルし直します）。`fx/` にエフェクトを置いていれば、「fx/ から選ぶ」でその一覧から選べます（下の「`fx/` の一覧」）。
   - 選んでいる物の .fx: 物を選んで「読み込む…」。「外す」で `default.fx` に戻ります。
   - ポストエフェクト: MMD と同じく、**アクセサリ**（下の「MME の物」）に当てた .fx がポストエフェクトになります。「足す…」で .fx を選ぶと、名前が .fx の拡張子を `.x` にしたもの（`ray.fx` なら `ray.x`）のアクセサリを場面の最後に置いて、その Main に当てます。一覧はアクセサリを並べたもので、「使う」のチェックでオン・オフ（アクセサリを隠す。ビューポートでも書き出しでも）、↑↓で並べ替え（アウトライナーでのアクセサリの並びが変わります）、✕で外せます（アクセサリを消します）。上のものほど先に（場面の近くで）かかります。
   - それぞれにコンパイルの結果が出て、誤りや警告は開くと全部読めます。描くときの警告（使えない書き方・GPU で使えない形式など）は「描くときの警告」にまとまります。
   - 「エフェクト割当」: MME の「MMEffect › エフェクト割当」と同じく、「Main」と、読み込んだエフェクトが宣言したオフスクリーン（`MaterialMap` など。説明も出ます）のタブがあり、ステージ（あれば先頭に「ステージ: .pmx のファイル名」）と場面の物が並びます（MMD モデルとステージは開くと材質が並びます）。行ごとに、読み込んだフォルダの .fx・「非表示」・「既定に戻す」を選べます。選んでいない行には、既定で描くもの（オフスクリーンでは `DefaultEffect` の規則で決まるもの）が薄い字で出ます。材質の割り当てが物の割り当てより先に効きます。
   - 「コントローラー」: 描いている .fx が値を読むコントローラー（`CONTROLOBJECT` の `name`。`ray_controller.pmx` など）の名前が並びます。場面にない名前には「置く」ボタンが出て、押すとその名前のコントローラー（下の「MME の物」）を置いて選びます（勝手には置きません）。場面にある名前は、押すとその物を選んでサイドバーの「MME」のページを開きます。
   - 「.emm を読む…」・「.emm を書き出す」: MMD のエフェクト割当ファイル（下の「.emm」）。
3. 「標準」に戻すと、MME の資源を片付けて、元の絵に戻ります。レンダーエンジンが「MME 互換」のあいだは、「効果」の組み込みの効果はかかりません。

**MME の物（コントローラー・アクセサリ）**

MMD の `ray_controller.pmx` や `ray.x` の代わりに、形のない「MME の物」を置きます。.x の形は読み込まず、描きません（値だけです）。アウトライナーに出て、選ぶ・名前を変える・複製・消す・隠す・コレクションに入れる・保存・元に戻すが、ほかの物と同じにできます。どのエンジンでも描かれず、物を積む動きにも入りません。.fx は名前（`CONTROLOBJECT` の `name`・`DefaultEffect`）で読むので、名前は MMD のファイル名と同じにします（複製すると `ray.x.001` のようになるので、使うときは名前を変えます）。

- **コントローラー**: 項目（`SSAO+` など。0〜1）の値を持ちます。項目は、描いている .fx がその名前で読むもの（`CONTROLOBJECT` の `item`）です。MME の欄の「コントローラー」の「置く」か、MCP の `mme_add_controller` で置きます。
- **アクセサリ**: `X`・`Y`・`Z`・`Rx`・`Ry`・`Rz`・`Si`・`Tr` と表示を持ちます。既定は MMD と同じく `Si` = 1・`Tr` = 1、ほかは 0。位置は MMD の単位、回転は度です（MMD のアクセサリ操作と同じ）。表示は「隠しているか」です。当てた .fx の `CONTROLOBJECT`（`(self)` と `name="ray.x"` など）は、`X`〜`Tr`・`XYZ`・`Rxyz`・ワールド行列・表示を読みます。行列は `Si` の拡大 → `Rx`〜`Rz` の回転 → `X`〜`Z` の位置の順です（回転の順は Y・X・Z。MMD のボーンと同じ順にしましたが、MMD で確かめていません）。`CONTROLOBJECT` の `Rx`・`Ry`・`Rz`・`Rxyz` はラジアンで渡します（これも MMD では確かめていません）。モデルのアクセサリの項目（`Si` など）は 0 を渡します。
- 名前が同じ物がいくつかあるとき、`CONTROLOBJECT` は場面の並びで最初の物（モデル・アクセサリ・コントローラーのどれでも）を読み、なければステージを読みます。

**MME の値・パラメータ・キーフレーム**

MME の物か、MME 互換のあいだの MMD モデルを選ぶと、サイドバーに「MME」のページが出ます。

- コントローラーは項目ごとのスライダー（0〜1）、アクセサリは `X`〜`Tr` の数の欄（`Si`（0〜10）・`Tr` はスライダーも）。
- 「エフェクトのパラメータ」: その物に当てた .fx（アクセサリはポストエフェクト、モデルは Main とオフスクリーンのタブのもの）ごとに、.fx の**パラメータ**が並びます。パラメータは、初期値を持つ数の uniform（`float`〜`float4`・`int`・`bool`）のうち、セマンティクスのないもの（MME が値を入れるもの・`CONTROLOBJECT` は入りません）です。注釈の `UIName`（名前）・`UIMin`・`UIMax`（範囲。なければ初期値から決めます）・`UIWidget = "Color"`（色の欄）・`UIHidden`（出さない）を読みます。値は「.fx を当てた物」と「.fx」の組ごとで、範囲に収めます。同じ .fx を 2 つの物に当てても、物ごとに別の値です。`DefaultEffect` だけで決まった物の .fx は初期値のままです。
- 値ごとの ◆ で、いまのフレームにキーフレームを打ちます（もう一度押すと消します）。選んだ物で I を押すと、ページに出ている値の全部にキーを打ちます。キーは物の **MME のチャンネル**になり、タイムライン（チャンネルの行は `MME: SSAO+` など）・グラフエディター・コピーと貼り付け・補間曲線・元に戻す・保存が、ほかのキーと同じに効きます。チャンネルの名前は、コントローラーの項目は項目名（`SSAO+`）、アクセサリは `X`〜`Tr`、パラメータは `<フォルダの id>/<.fx のパス>:<名前>`（ベクトルは `:x`・`:y`・`:z`・`:w` の成分ごと）です。値を変えると元に戻すの対象になり、スライダーを動かしているあいだは 1 回にまとまります。
- ステージに当てた .fx のパラメータは場面の値で、キーフレームは打てません（ステージは物でないため）。画面には出ないので、MCP の `mme_set_values`（`object: "stage"`）で変えます。

**.emm（MME のエフェクト割当ファイル）**

- 「.emm を読む…」で MMD（MME）のエフェクト割当ファイルを読み、割り当てを戻します。物は名前で照らします: `[Object]` のファイル名を、モデルの .pmx のファイル名・MME の物の名前・ステージの .pmx のファイル名と比べます（大文字小文字は問いません。同じ名前がいくつかあれば、.emm の番号の順に場面の並びの順で当てます）。合った物の割り当ては .emm のものに置き換えます。場面にない `.x` はその名前のアクセサリを置き（Main に割り当てがなければ、同じ名前の .fx を探して当てます）、場面にない .pmx は飛ばします。.fx のパスは、読み込んであるフォルダの中で、パスの後ろの部分がいちばん長く合うもの（大文字小文字・`\` と `/` は問いません）にします。合わない物・見つからない .fx は警告にまとめて、残りは当てます。見つからない .fx の行の割り当ては、いまのまま残します（行が全部見つからない物は何も変えません。.fx のフォルダを読み込んでから読み直すと当たります）。読み込みは 1 回の「元に戻す」で戻ります（ステージの割り当ては場面の値なので戻りません）。先に、.emm が使う .fx のフォルダを読み込んでおいてください。
- 「.emm を書き出す」で、いまの割り当てを `<プロジェクトの名前>.emm`（Shift_JIS・CRLF。MME と同じ書式）にします。物の番号は場面の並び（モデルと MME の物。最後にステージ）で、モデルは `Pmd`、アクセサリは `Acs` です。.fx のパスは `フォルダの名前\フォルダの中のパス`（`ray-mmd-1.5.2\Main\main.fx` など）の相対パスです。
- **書き出した .emm を MMD で使うには**: MME は相対パスを（.emm の場所ではなく）MMD のフォルダ（`MikuMikuDance.exe` のあるフォルダ）から読みます。そこで、.fx のフォルダ（`ray-mmd-1.5.2` など）を MMD のフォルダの直下に置き、.emm もそこに置いて（どこに置いても読めますが、まとめておくと分かりやすい）、MMD の「MMEffect › エフェクト割当」の「ファイル › 設定を読む」で読みます。`[Object]` はファイル名だけを書くので（このアプリは .pmx の置き場所を知りません）、MME がそれで物を照らすかは確かめていません。合わなければ、MMD で同じ名前のモデル・アクセサリを読み込んでから読んでください。
- 書式の細かい点（調べた見本と、読み書きで決めたこと）は [docs/superpowers/notes/2026-10-05-emm-format.md](docs/superpowers/notes/2026-10-05-emm-format.md) にあります。

**`fx/` の一覧**

アプリを配っているサーバー（`npm run dev`・`npm run preview`・MCP サーバー）が動いているときは、「読み込む…」（物の .fx）・「足す…」（ポストエフェクト）の隣に「fx/ から選ぶ」が出て、`fx/` の直下のフォルダを `.fx` の数と大きさつきで並べます。選ぶと、そのフォルダのファイル全部を、フォルダを選んだときと同じように読み込みます。場所は環境変数 `WEBGL_GRID_FX_DIR` で変えられ、デスクトップ版は「書類/webgl-grid/fx」です。静的に配っているとき（GitHub Pages など）や、`fx/` に .fx がないときは出しません。詳しくは [fx/README.md](fx/README.md)。

**保存**

割り当て（タブ・物・材質ごと。ステージのものも）・MME の物とその値とキー・パラメータの値・読み込んだフォルダはプロジェクトに保存されます。「ファイルも入れる」（.wgp）で保存すると、実際に読んだファイル（.fx・`#include`・画像）だけを入れます。参照だけ（.wgpj）のときは、開くときにそのフォルダのファイルを探してもらいます。物ごとの割り当て・MME の物の値・パラメータの値は物の値なので、複製に写り、元に戻せます。ステージの割り当てとパラメータの値は場面の値なので元に戻すの対象にならず、ステージの .pmx のファイル名と一緒に覚えます: ステージを名前の違う .pmx に差し替えると当たらず（前の空の .fx が会場に当たらない）、名前のまま残って、元の .pmx に戻すとまた当たります（差し替えたステージで割り当てを変えると、新しいステージのものに置き換わります）。

前の版（ポストエフェクトの一覧とコントローラーのスライダーを場面の値として持っていたころ）のプロジェクトを開くと、ポストエフェクトは同じ並びとオン・オフのアクセサリ（名前は .fx の拡張子を `.x` にしたもの）に、スライダーの値はその名前のコントローラーに、名前のないステージの割り当ては一緒に開いたステージのものに移り、同じ絵になります（ポストエフェクトの `(self)` のアクセサリの値は、前の版では 0 でしたが、移したあとは MMD の既定（`Si` = `Tr` = 1）を読みます）。移せなかったもの（名前が空のコントローラーなど）は「開きました」のお知らせに出ます。

**Ray-MMD を使う**

Ray-MMD 1.5.2 の標準の構成（`ray.conf` のまま）に、ライトとフォグを足したものを動かします。MME に渡す世界は MMD の単位なので（下の「座標の大きさ」）、太陽の陰影と影・材質（肌・髪の SSS など）・ライト・フォグが描かれるようになりました。空（Time of day）は、Ray-MMD の Mie 散乱の係数の式を MMD の絵に合うように書き換えて（`core/fx/compat.ts`）、MMD と同じ青い空になります。

1. [Ray-MMD 1.5.2](https://github.com/ray-cast/ray-mmd/tree/1.5.2)（MIT ライセンス）を `fx/ray-mmd-1.5.2/` に置きます（[fx/README.md](fx/README.md)。デスクトップ版は「書類/webgl-grid/fx/ray-mmd-1.5.2/」）。
2. レンダーエンジンを「MME 互換」にして、「効果」のタブの「ポストエフェクト」の「足す…」の隣の「fx/ から選ぶ」で `ray-mmd-1.5.2` を選び、`ray.fx` を選びます（`fx/` を使わないときは「足す…」で `ray-mmd-1.5.2` のフォルダを選びます）。MMD で `ray.x` を読み込むのと同じく、アクセサリ `ray.x` が場面の最後に置かれ、`ray.fx` が当たります。
3. 「コントローラー」に `ray_controller.pmx` が出るので、「置く」で置きます。サイドバーの「MME」のページで、項目（`SunLight+`・`Exposure+`・`SSAO+` など）の値を 0〜1 で入れ、◆ でキーフレームを打てます（`Exposure+` を 0 → 1 にすると、だんだん明るくなります）。`ray.x` を選ぶと、アクセサリの値が出ます。`ray.fx` にはいじれるパラメータ（初期値を持つ数の uniform）がありません（値は全部 `static`・`const`・`#define` で、Ray-MMD の設定は `ray.conf` の `#define` で決まります。変えるときは `ray.conf` を書き換えてフォルダを読み直します）。
4. モデル（.pmx）を読み込むと、`MaterialMap` のタブの既定（`DefaultEffect`）で `Materials/material_2.0.fx` が当たります。材質ごとに変えるときは、`MaterialMap` のタブでモデルを開いて、材質の行に `Materials/Skin/…`・`Materials/Hair/…` などを選びます。Main のタブには `Main/main.fx` を選びます（Ray-MMD の決まり。`default.fx` のままだと、MMD の陰影が上に重なります）。
5. ライトは `Lighting/` の .pmx（`PointLight.pmx` など）を、フォグは `Fog/` の .pmx を読み込みます。`LightMap` のタブの既定（`DefaultEffect`）で、ライトの種類ごとのフォルダの `Default/`（LED は `Default LED/`）の .fx が、`FogMap` のタブの既定で、フォグの種類ごとのフォルダの .fx が当たります。色や強さは、その .pmx のモーフ（`R+`・`G+`・`B+`・`Intensity+` など）で決まります。
6. 空（`Skybox/Time of day/Time of day.pmx`）を読み込むと、大きいのでステージになります（原点に置かれ、いちばん先に描かれます。Ray-MMD の説明の「model disply order」のとおり）。エフェクト割当の「ステージ」の行に、Ray-MMD の説明（同じフォルダの `README.png`）のとおり、Main に `Time of day.fx`・`FogMap` に `Time of fog.fx`・`EnvLightMap` に `Time of lighting.fx`・`MaterialMap` に `Materials/material_skybox.fx` を割り当てます。ステージは 1 つだけなので、空をステージにすると、ほかのステージ（会場の .pmx）は同時に使えません。
7. MMD で作った Ray-MMD の場面の .emm があれば、手順 2 でフォルダを読み込んだあと「.emm を読む…」で割り当てを戻せます（モデル・ステージは先に読み込んでおきます）。

MCP からも同じ構成を組めます（`e2e/mme-mcp-local.spec.ts` が、この順に組んで書き出します）: `mme_set`（`engine: "mme"`）→ `mme_list_fx`・`mme_load_folder`（`ray-mmd-1.5.2`）→ `load_files`（モデル・ライト・フォグの .pmx と空の .pmx）→ `mme_add_accessory`（`name: "ray.x"`・`fx: { folder: "ray-mmd-1.5.2", path: "ray.fx" }`）→ `mme_state` の `tabs` に `MaterialMap` などが出るのを待つ（ray.fx を一度描くと出ます）→ `mme_assign`（モデルの Main・材質ごとの `MaterialMap`、`object: "stage"` の Main・`EnvLightMap`・`FogMap`・`MaterialMap`）→ `mme_add_controller`（`ray_controller.pmx`）→ `mme_set_values`・`insert_keyframe`（`channels: ["Exposure+"]`）→ `render_image`・`render_animation`。

手元（Apple M3 Max・Chrome（Playwright の Chromium）・GPU で描く）で、ray.fx・材質の .fx 3 つ・空・ライト 10 種類・フォグ 4 種類を置いた場面を 1280×720 で描くと、1 フレームは、全部見えているとき **8 ms 前後（125 fps ほど）**、ライト 8 種類とフォグ 3 種類を書き出しで隠して、点光源・スポットライト・グラウンドフォグ・空に絞ったとき **5.7 ms 前後（175 fps ほど）** でした（どちらもアクセサリ `ray.x` とコントローラーの物 `ray_controller.pmx` で組んだ場面。`e2e/ray-mmd-local.spec.ts` が両方を測って出します）。

**いまできること**

- 物の .fx: MME の決まりで書かれた .fx（`MMDPass`・`Subset`・`UseTexture`・`UseSphereMap`・`UseToon`・`UseSelfShadow` による technique の選び方で、トゥーン・スフィア・輪郭線・地面の影・セルフシャドウの pass を描き分けます。合う technique がない pass は `default.fx` で描きます）。物の technique の Script（`LoopByCount`・レンダーターゲットへの描画など）も動きます。
- ポストエフェクト: Script と `ScriptExternal=Color` の入れ子、`ScriptOrder`（`preprocess` は場面の前に描きます）、レンダーターゲット（`ViewportRatio`・`Dimensions`・RGBA8 / 16F / 32F・R / RG・L8・ミップマップ・MRT・深度ターゲット・`shared`）。
- オフスクリーン（`OFFSCREENRENDERTARGET`）: `DefaultEffect`（`self`・`hide`・`none`・ワイルドカード）、エフェクト割当のタブ、物の .fx が宣言する入れ子のオフスクリーン（`(OffscreenOwner)`）。
- ステージの割り当て: ステージ（MMD モデル）にも、置いた物と同じくタブ・材質ごとに .fx を割り当てられます（材質 → 物 → `DefaultEffect`（.pmx のファイル名で照らします）→ Main では `default.fx` の順）。ステージを描く .fx の `(self)` はステージです。
- `CONTROLOBJECT`: 場面の物（.pmx のファイル名か物の名前で探します。なければステージの .pmx のファイル名）のワールド行列・位置・表示・骨・モーフと、コントローラーの項目・アクセサリの `X`〜`Tr`（上の「MME の物」）。場面にない名前は 0 です（MME の欄の「コントローラー」に「置く」が出ます）。
- 座標の大きさ: MME に渡す世界は MMD の単位（このアプリの世界の 10 倍）の左手系です。MMD モデル（置いた物とステージ）は、MMD と同じく `WORLD` が単位行列で、置いた場所・向き・大きさは頂点に入れて渡します。形などほかの物は `WORLD` で置きます。カメラ・ライト・`CONTROLOBJECT` の位置も 10 倍で、カメラの遠い面は MMD と同じく遠く（100000 以上）にします。セルフシャドウの範囲（影の距離）と地面の影は、いままでと同じ大きさになるように MMD の単位で決めています。
- 骨・SDEF・QDEF・頂点モーフの変形は CPU で MMD と同じに計算し（MME の左手系で渡します）、輪郭線も MMD の式で広げます。骨の変形は、オフスクリーンがいくつあっても 1 フレームに 1 回です。
- .fx が知っている値（`WORLD`・`VIEW`・`PROJECTION` と、材質・ライト・カメラ・時刻・描画先の大きさなどのセマンティクス）。`TIME`・`ELAPSEDTIME` はタイムラインの時間から作ります。画像のテクスチャは png・jpg・bmp・gif・webp・tga・hdr・dds（無圧縮・DXT・キューブマップ・ミップ）。サンプラーの `SRGBTexture` は 8 ビット RGBA の画像で効きます。HLSL の `pow` と `normalize` は D3D9 と同じく、`pow` は |x|^y、`normalize` は 0 のベクトルを 0 にします（GL のままだと NaN になります）。
- 書き出し（PNG・動画）の大きさに合わせて描き直します（レンダーターゲットの大きさも書き出しの大きさに従います）。

**できないこと・気をつけること**

- MMD の絵に合わせた書き換え: Ray-MMD の空（Time of day・Time of night・`AtmosphericFog`）が使う Mie 散乱の係数（`Shader/PhaseFunctions.fxsub` の `ComputeWaveLengthMie`）の `pow(lambda, U - 2)` は、HLSL どおりに計算すると係数が大きすぎて空が真っ黒になります。`lambda` とみなすと MMD の絵（Ray-MMD のドキュメントの画面）に合うので、その行だけを書き換えて読み込みます（`core/fx/compat.ts`。ほかの `pow` は変わりません）。D3D9 で実際に何が起きているかは未確認です（設計書の Ruling 18）。
- 大きい .pmx（横幅か奥行きが MMD の単位で 40 を超えるもの）はステージになります。ステージは 1 つだけなので、Ray-MMD の空（Time of day）をステージにすると、会場のステージと同時には使えません。置いた物は積み重なるので、空の球を置いた物にすると、ほかの物が上に乗ります。
- .emm の近似: 同じ名前のオフスクリーンを別の持ち主が宣言した節（`[Effect@名前(1)]`）は、名前ごとの 1 つのタブにまとめます（先の節が勝ちます）。オフスクリーンのタブの `none`（MME の「普通の描き方」）は、このアプリでは「割り当てなし」（`DefaultEffect` の規則）になります。書き出すとき、Shift_JIS で書けない文字は `?` になります。
- このあともできないもの:
  - .x の形の読み込みと描画（アクセサリは値だけ）、ステージのパラメータのキーフレーム。
  - 第 5 の計画: `ANIMATEDTEXTURE`（GIF の動画の材質。Ray-MMD の `Materials/Video` の一部）、アルファテスト（`AlphaTestEnable` は無視して警告）、`VFACE` の向きの直し。
  - 計画に入っていないもの: 物の .fx の `Draw=Buffer`、UV モーフ。
  - 直さない近似: サンプラーの `BORDER` は `CLAMP` にします（警告が出ます）。WebGL2 には境界の色で埋める折り返し（`CLAMP_TO_BORDER`）がなく、まねるにはシェーダーを書き換える必要があるためです。Ray-MMD のブルームでは、絵の端の色が少しにじむことがあります。
- ポストエフェクトがあるあいだは、描いた絵を画面の大きさの中間の絵に描いてから canvas に写すので、アンチエイリアス（MSAA）がかからず、グリッドや編集用の目印はモデルに隠れません。
- 浮動小数のテクスチャに描けない GPU では、セルフシャドウを切り、浮動小数のレンダーターゲットを使うエフェクトを止めます（警告が出ます）。GPU で使えない .fx は止めて、Main の物は `default.fx` で描き、オフスクリーンでは描きません。
- デフォーマで変形した MMD モデルの複製（クローナーのクローン）は、元の .pmx を引けないので MME 互換では描けません（警告が出ます）。元のモデルは変形した形のまま描かれます。
- 「シーン」の床（「床を置く」）は MME 互換では描きません。ポイントライト・スポットライトも使いません（MME のライトは太陽 1 つだけです。Ray-MMD のライトは .pmx を置きます）。
- ポストエフェクトがないとき（canvas に直接描くとき）は、両面（`CullMode = NONE`）の面で `VFACE` の表と裏が逆になります（第 5 の計画で直します）。

**開発の道具**

- `fx/` — 手持ちのエフェクトを、エフェクトの一式ごとのフォルダにして置く場所。中身は Git に入りません（[fx/README.md](fx/README.md)）。
- `npm run fx:check` — `fx/` と `third_party/ray-mmd-1.5.2/` の .fx を全部変換して、ファイルごとの結果（`成功` か最初の誤りの種類）・場所・時間と、成功の数・誤りの種類ごとの数・いちばん遅いものを表にします（`node scripts/fx-check.ts [フォルダ…]` で、フォルダを選べます）。
- `npm run mme:bench` — CPU の変形の速さを測ります。5 万頂点（BDEF2 が 7 割・BDEF4 が 2 割・SDEF が 1 割）・骨 200 本・頂点モーフ 30 個（重みが 0 でないのは 5 個。種類は頂点の順にかき混ぜる）の合成データで、モーフ → 骨 → 輪郭線を 200 回くり返した 1 回の平均を出します。手元（Apple M3 Max・Node 26）では **1 回 4.3 ms 前後**で、30 fps（33 ms）の予算に十分収まります。
- 見本として Ray-MMD 1.5.2 を `third_party/ray-mmd-1.5.2/` に入れています（MIT ライセンス。同じフォルダの `LICENSE.txt`）。単体テストで、その .fx 全部（`ray.conf` の切り替えごとの `ray.fx` も）が誤りなく変換できることを確かめます。
- コンパイラのいまの限り: `asm` ブロック・Shader Model 4 以降の書き方・`tx_1_0` の TextureShader は変換できません（`FX-UNSUPPORTED`）。入れ子の配列の初期値は、波括弧で全部囲むか、要素ごとに平らに並べます。vs_2_0・ps_2_0 で `COLORn` の値を [0, 1] に収める動きはまねしません（vs_3_0 はもともと収めません）。

## テスト

```bash
npm test               # 単体テスト (Vitest)
npx playwright install chromium   # 初回だけ: e2e 用のブラウザ
npm run test:e2e       # e2e テスト (Playwright。開発サーバーを立ち上げて、本物のブラウザで操作する)
npm run lint           # lint (oxlint。Rust 製で、全体を 0.3 秒ほどで見る)
npm run test:all       # 型チェック・lint・単体テスト・e2e を同時に動かす (Mac で 10 秒ほど)
```

- 速くするための工夫:
  - 型チェックは、Go で書かれた TypeScript 7（ネイティブ版）。
  - 単体テストは、ファイルごとに並列に動く Vitest。ビルドは Rust で書かれた Rolldown（Vite 8）。
  - e2e は、テストごとに並列に動く Playwright。開発サーバーではなく、ビルドした 1 つのファイルを `vite preview` で配ります（ページの読み込みが速い）。
  - e2e の WebGL は、Mac では GPU（Metal）で描きます。GPU のない CI などではソフトウェア描画（SwiftShader）にします。`E2E_GL=gpu` / `E2E_GL=software` で切り替えられます。
  - `npm run test:all` は、型チェック・単体テスト・e2e を同時に動かします（`scripts/test-all.mjs`）。
- e2e で使う MMD モデルは、配布の決まりがあるモデルをリポジトリに入れないように、`e2e/fixtures/pmx.ts` でテストのたびに小さな PMX（四角柱 1 本、ボーン 2 本、表情 1 つ。物理演算のテストでは剛体と関節、錘で形を保つ髪も）を、`e2e/fixtures/vmd.ts` で小さな VMD を組み立てています。WebGL は GPU のない環境でも動くよう、ソフトウェア描画（SwiftShader）で動かします。

## しくみ

- 描画は three.js（0.186）です。PMX・VMD の読み込みと MMD の動き（MMDLoader・MMDAnimationHelper・MMDPhysics など）は、three.js が r172 で本体から外したので、外される前の r171 のものを `src/vendor/three-mmd/` に取り込んで使っています（これで three.js 本体は新しい版にできます）。MMD の読み込みや後処理などの大きな部品は、初めて使うときに読み込みます（Vite がファイルを分けます）。
- 画面の部品は React で、three.js の場面はエンジン（`src/engine`）が持ちます。エンジンは状態が変わると `UiChannel` のストアに書き、部品は `useUi`（`useSyncExternalStore`）でそれを読んで描き直します。毎フレーム変わるもの（再生中の表情・ボーンの値）は、描き直しを 0.1 秒に 1 回に間引きます。タイムラインとナビゲーションギズモは 2D の canvas に直接描きます。
- 地面は大きな板に専用のシェーダーを当てて描いています。Blender の床のように面は塗らず、`fwidth` で距離に関係なく線幅が一定になるようにアンチエイリアスした 1 単位ごとの細線と 5 単位ごとの太線、X 軸（赤）と Z 軸（青）だけを引き、遠くほど透明にしています。
- マテリアルは three.js の物理ベースの材質（`MeshPhysicalMaterial`）で描き、ノードツリーから組み立てた GLSL を `onBeforeCompile` で差し込みます（ベースカラー・アルファ・メタリック・粗さ・放射）。つながっていない入力は uniform にし、形が同じなら `customProgramCacheKey` で同じシェーダーを使い回します。IOR などのつなげない入力と、ノーマルマップ（画像テクスチャ → ノーマルマップ → 法線）は材質の値として入れます。映り込みと環境の光は、three.js の `RoomEnvironment` から作ります。
- MMD の輪郭線と、選択中のオレンジの輪郭線は three.js の `OutlineEffect` です（マテリアルの輪郭線の設定から毎回作り、選んでいる物だけオレンジにする）。
- 手で動かしたボーンは、モーションのないモデルでは、最初の姿勢に戻してから手の値を当て、`CCDIKSolver`（IK）と付与を計算し直します。物理演算で動く骨はそのままにします。モーションのあるモデルでは、毎フレームのモーションのあとに手の値を当てます。
- モーションの再生（カメラを含む）は three.js の `MMDAnimationHelper` です。モーションは繰り返さずに最後の姿勢で止まる設定にして、タイムラインの時刻に合わせて動かし、飛んだときは物理演算をその姿勢になじませます。
- 物理演算は three.js の `MMDPhysics` と Ammo.js（Bullet の WebAssembly 版）です。`MMDPhysics` は剛体を「拡大縮小していないモデル自身の座標」で扱いますが、縮小したモデルでは剛体を作るとき・置き直すとき（`reset`）・続けて計算するとき（`warmup`）に座標がずれるので、呼ぶ間だけモデルを等倍・親なしにしています（ずれると剛体が遠くへ飛ばされ、髪とスカートが絡まって巻き上がる）。またモデル自身の座標で計算するので、置き場所の加速度を「見かけの重力」として足し、縦軸まわりに回したときは剛体ごとにオイラー力・遠心力・コリオリ力をかけています。モデルを消しても、Ammo.js 側のメモリは解放されません。
- 効果は three.js の `EffectComposer` で後処理しています（`GTAOPass`・`BokehPass`・`UnrealBloomPass` 2 つ・色調の `ShaderPass`・`OutputPass`）。効果を 1 つも使わないときは、後処理を通さずに描きます。
- 影は平行光源のシャドウマップです。物を掴む判定は three.js のレイキャストで、見た目の形どおりに当たります（PMX モデルは、骨やモーフの計算をしない判定用の複製で判定して速くしています）。
- 積み重ねは簡単な重力で処理しています。上から見た足場（回転した長方形どうしを分離軸判定で調べる）が重なる物があればその上に、なければ地面まで落とし、落ちるときは重力加速度で加速して着地で小さく跳ねます。
