# webgl-grid

three.js で描いた無限に続くグリッドの上に、立方体・トーラス・三角錐や MMD モデル（.pmx）やステージを置いて、モーション（.vmd）と曲で踊らせたり、キーフレームでポーズのアニメーションを作ったりできるアプリです。画面は Blender（4.x）のアニメーション作業の画面を手本にしています。

React + TypeScript + Vite で作っています。GitHub Pages での公開は停止中です。

## 動かす

Node.js（20 以降）が必要です。

```bash
npm install
npm run dev
```

表示された http://localhost:5173/ を開きます。`npm run build` で `dist/` に書き出せます（相対パスで参照するので、どのフォルダに置いても開けます）。three.js の物理演算に使う Ammo.js だけは、剛体を持つモデルを初めて読み込んだときに CDN（jsDelivr）から取ってきます。

WebGL2 に対応したブラウザが必要です。URL に `?debug` を付けて開くと、動作確認用にエンジンを `window.engine` としてブラウザのコンソールから触れます（e2e テストもこれを使います）。

## 画面

| 領域 | 内容 |
| --- | --- |
| 上のバー | 「ファイル」（MMD を読み込む・ポーズの保存と読み込み・最初の状態に戻す）、「ヘルプ」（ショートカットの一覧） |
| 3D ビューポート | 見出しに「ビュー」「追加」「オブジェクト」のメニュー。左上にカメラの操作（回転・移動）のツールと「ユーザー・透視投影 / (フレーム) 選んでいる物」の表示、右上にナビゲーションギズモ（軸の丸をクリックするとその向きから見る）と視点を戻すボタン |
| サイドバー | 右端の縦書きのタブで「オブジェクト」（名前・位置・回転・色・削除・髪を重力で垂らす）、「マテリアル」（モデルの材質）、「表情」、「ボーン」（とポーズファイル）、「効果」を切り替える。幅の狭い画面では、ビューポートの上に重ねて出す |
| タイムライン | キーフレームの挿入・削除、再生ボタン（最初へ・前のキー・再生/停止・次のキー・最後へ）、いまのフレーム・開始・終了の欄。下の目盛りで再生位置（青い再生ヘッド）を動かし、選んでいるモデルのキーフレーム（◆）とモーションのキーフレーム（小さな灰色の ◆）、カメラモーションを並べる |

数値のスライダーは Blender と同じく、左右にドラッグで値を変え、クリック（または Enter）で数値を打てます。スマホでは触った位置の値になります。

## 操作

以下の「物」は、立方体・トーラス・三角錐・読み込んだ PMX モデルのどれにも当てはまります（色を変える操作は形だけ）。

| 操作 | 内容 |
| --- | --- |
| 追加 > 立方体 / トーラス / 三角錐（Shift+A） | 画面中央の近くに置いて選ぶ（最大32個。8色のうち使われていない色を優先） |
| ファイル > MMD を読み込む…（Ctrl+O） | .pmx とテクスチャ画像をまとめて選ぶと、モデルを置く（ステージの .pmx なら原点に）。.vmd（ダンス・カメラ）、.vpd（ポーズ）、曲も一緒に選べる |
| 物をクリック / タップ | 選ぶ（オレンジの輪郭線）。何もない所をクリックすると選択を解除（Alt+A でも解除） |
| 形をタップ（スマホ） | 選んで、8色のパレットを出す |
| 何もない地面を長押し（スマホ） | 最後に追加した形をその場所に置く（ほかの物と重なる位置なら上に積む） |
| 物をドラッグ（スマホは長押ししてから） | 運ぶ。ほかの物の上まで運ぶとその上に積まれ、上に載っている物も一緒に運ばれる。離すと下に落ちる |
| 物を Shift+ドラッグ / 2本指でひねる（スマホ） | 縦軸まわりに回す（上に載っている物も一緒に回る） |
| 物をダブルクリック / ダブルタップ、X / Delete | 削除する（上に載っていた物は下に落ちる）。タイムラインの上で X を押すと、選んだキーフレームを削除 |
| ドラッグ（回転 / 移動のツール） | 注視点のまわりを回る / 地面に沿って平行移動する |
| ホイール / ピンチ（スマホ） | ズームイン / ズームアウト |
| テンキー 1 / 3 / 7、ギズモの軸 | 前 / 右 / 上から見る |
| Home | 視点を戻す（タイムラインの上では、開始〜終了の全体を表示） |
| N | サイドバーを出す・隠す |
| Space | 再生 / 停止 |
| ← / → 、Shift+← / → | 前 / 次のフレーム、最初 / 最後のフレーム |
| ↓ / ↑ | 前 / 次のキーフレーム（キーフレームとモーションのキーフレーム） |
| I / Alt+I | 選んでいるモデルのいまのポーズと表情を、いまのフレームのキーフレームにする / いまのフレームのキーフレームを削除 |
| タイムラインの ◆ をクリック・ドラッグ | キーフレームを選ぶ（Shift で追加）・左右にずらす |
| タイムラインでホイール / Shift+ホイール | 拡大縮小 / 左右に動かす |

## キーフレームとタイムライン

- 時刻はタイムラインが持ち、モーション（.vmd）・カメラモーション・曲・キーフレームをそれに合わせます。再生すると、終了フレームまで行ったら開始フレームに戻って繰り返します（Blender と同じ）。フレームは MMD と同じ 1 秒 30 フレームです。
- モーションや曲を読み込むと、終了フレームをその長さに合わせ、最初から再生します。ダンス・カメラ・曲はずれないように同じ時刻にそろえます。曲があるときは、曲の再生位置に合わせて進めます。
- キーフレームは、選んでいるモデルの「手で動かしたボーン」と表情を記録します。キーフレームのあいだは、回転を球面線形補間、位置と表情を線形補間でつなぎます。キーフレームのあるモデルは、フレームを動かすとキーフレームの値に戻ります（手で動かした値を残すにはキーフレームを挿入します）。
- モーションのあるモデルでは、手で動かしたボーンとキーフレームがモーションより優先されます。

## MMD モデルとモーション

- モデルの `.pmx` と、モデルが使うテクスチャ画像（`.png` `.bmp` `.tga` `.spa` `.sph` など）を**まとめて**選んでください。テクスチャがサブフォルダにある場合も、画像ファイルを一緒に選べばファイル名で対応づけます。見つからないテクスチャは画面上部に表示します。
- モデルは MMD の 1 単位を 0.1 として置きます（標準的な身長 20 のモデルが立方体 2 個分の高さ）。どのモデルも同じ倍率なので、人物とステージの大きさの関係は MMD と同じです。
- **ステージ**: 横幅か奥行きが 40（MMD の単位）を超えるか、名前に「ステージ」「stage」「舞台」を含む .pmx は、ステージとして原点に置きます。1 つだけで、掴んだり積んだりはできません。ステージがあるあいだは地面のグリッドを隠します。
- 選んだファイルはブラウザの中だけで読み込み、どこにも送信しません。ページを再読み込みすると消えます。
- MMD の輪郭線を表示します。物理演算（髪やスカートの揺れ）も動き、運ぶと髪がなびき、落ちるとふわっと浮き、回すと振り出されます。
- **髪を重力で垂らす**: モデルによっては、髪の節ごとに何ともぶつからない剛体を固定の関節で付けて（錘）、重力の中でもモデルの作者が作った髪の形を保っています（MMD でも同じ形になります）。サイドバーの「オブジェクト」の「髪を重力で垂らす」をオンにすると、その錘を外して、髪を重力でまっすぐ垂らします。オフで元の形に戻ります。錘は、頭のボーン（「頭」）に付いた剛体からぶら下がる鎖の中だけで探すので、胸などほかの部分の錘はそのままです。このスイッチは、髪に錘のあるモデルでだけ出ます。
- モーション（.vmd）は、モデルと一緒に選ぶとそのモデルで、.vmd だけを選ぶと置いてあるモデル全員で再生します。骨と表情の動き、足の IK、連動する骨を計算します。カメラモーションは、ステージがあればステージの原点、なければ最初のモデルの向き・場所に合わせます。自分でカメラを動かすと、カメラモーションは止まり、その視点から手動の操作に切り替わります。
- ブラウザに曲の自動再生を止められたときは、画面をタップするか ▶ を押すと再生します。
- 表情（モーフ）はサイドバーの「表情」で、.pmx の分類どおり「眉・目・口・その他」に分けて動かせます。ボーンは「ボーン」で、.pmx の表示枠ごとのリストから選び、回転（−180〜180°）と、移動できるボーンは位置も変えられます。足の IK を動かすと、つながった骨がついてきます。
- **マテリアル**: サイドバーの「マテリアル」で、モデルの材質（髪・肌・服など、.pmx の材質）を一覧から選び、表示・非表示（一覧の目のボタンでも）、色、不透明度、環境色、反射色と反射の強さ、輪郭線（付けるか・色・太さ）を変えられます。テクスチャのある材質では、色はテクスチャに掛け合わされます。変えた材質には印が付き、「この材質を元に戻す」「すべて元に戻す」で読み込んだときの値に戻ります。選んでいるあいだは選択を示すオレンジの輪郭線で表示され、選択を解除すると決めた輪郭線になります。変えた値はページを再読み込みすると消えます。
- ポーズは MMD のポーズファイル（.vpd、Shift-JIS・左手系）として保存・読み込みできます。手で動かしたボーンといまの表情を保存します。MMD で保存した .vpd も読めます。
- モーションで体が動いても、掴む判定は読み込んだときの姿勢のままです。
- モデルの利用規約（再配布の禁止など）は、それぞれのモデルの readme に従ってください。このリポジトリでは `.pmx` と `げのげ式初音ミク/` を `.gitignore` で除外しています。

## 効果（MME 風）

MME（MikuMikuEffect）の .fx は DirectX 用の HLSL で書かれていて、ブラウザではそのまま動かせません。代わりに、よく使われる MME に近い効果を組み込みで用意しています。サイドバーの「効果」で、パネルの見出しのチェックでオン・オフ、スライダーで強さを変えます。オフの効果のスライダーを動かすと、その効果がオンになります。設定はブラウザに保存されます。

| 効果 | 近い MME | 内容 | スライダー |
| --- | --- | --- | --- |
| 光る | AutoLuminous | ごく明るい部分だけを光らせてにじませる | 強さ（0〜2、初期値 0.7） |
| ふんわり | Diffusion | 画面全体に弱い光のにじみをかける | 強さ（0〜1、初期値 0.2） |
| 被写界深度 | DOF 系 | 注視点にピントを合わせ、それ以外をぼかす | ぼけの大きさ（0〜3 倍、初期値 1 倍） |
| 影の濃さ | SSAO 系 | 物の接する所や隙間を暗くする（GTAO） | 濃さ（0〜2、初期値 1） |
| 色調 | 色調補正系 | 画面に出す直前に色を整える | 色温度（−1〜1）・彩度（0〜2）・明度（0〜2） |

効果をオンにすると描画が重くなります。スマホでは特に「被写界深度」と「影の濃さ」が重くなりやすいです。

## テスト

```bash
npm test               # 単体テスト (Vitest)
npx playwright install chromium   # 初回だけ: e2e 用のブラウザ
npm run test:e2e       # e2e テスト (Playwright。開発サーバーを立ち上げて、本物のブラウザで操作する)
npm run test:all       # 型チェック・単体テスト・e2e を同時に動かす (Mac で 7 秒ほど)
```

- **単体テスト**（`src/**/*.test.ts(x)`）: 材質の読み書きと元に戻す（選択中の輪郭線との兼ね合いも）、髪の錘の見つけ方、タイムライン（`Clock`）、描画先なしで組み立てたエンジン（追加・積み重ね・削除・選択・最初の状態に戻す・キーフレームの挿入と補間・移動・削除・前後のキーへの移動）、キーフレームの補間、積み重ねの判定と高さ・空いている場所の探し方、.vpd の書き出しと読み取り（左手系との変換、MMD の書式）、Shift-JIS への変換、ストア、タイムラインの目盛りと拡大縮小、スライダーと数値の欄（jsdom + Testing Library）。
- **e2e テスト**（`e2e/`）: 最初の画面、追加メニュー、クリックでの選択と解除、ドラッグで積む、削除、サイドバーでの位置と色、視点とサイドバーのショートカット、効果のオン・オフと保存、タイムラインの再生・目盛り・フレームの欄・繰り返し、MMD モデルの読み込み・表情・ボーン・キーフレームの補間と削除・.vpd の保存と読み込み、マテリアル（色・不透明度・表示・輪郭線を変えて元に戻す）、物理演算（モーションのあるモデルでタイムラインを飛んだり繰り返したりしても、剛体がボーンから離れないこと・「髪を重力で垂らす」で髪が垂れ、オフで戻ること）、スマホの画面（サイドバーの重ね表示、横にはみ出さないこと）。
- 速くするための工夫:
  - 型チェックは、Go で書かれた TypeScript 7（ネイティブ版）。
  - 単体テストは、ファイルごとに並列に動く Vitest。ビルドは Rust で書かれた Rolldown（Vite 8）。
  - e2e は、テストごとに並列に動く Playwright。開発サーバーではなく、ビルドした 1 つのファイルを `vite preview` で配ります（ページの読み込みが速い）。
  - e2e の WebGL は、Mac では GPU（Metal）で描きます。GPU のない CI などではソフトウェア描画（SwiftShader）にします。`E2E_GL=gpu` / `E2E_GL=software` で切り替えられます。
  - e2e では、物理エンジン Ammo.js を CDN から取らず、`node_modules` から返します（`e2e/fixtures/test.ts`。インターネットにつながっていなくても動きます）。
  - `npm run test:all` は、型チェック・単体テスト・e2e を同時に動かします（`scripts/test-all.mjs`）。
- e2e で使う MMD モデルは、配布の決まりがあるモデルをリポジトリに入れないように、`e2e/fixtures/pmx.ts` でテストのたびに小さな PMX（四角柱 1 本、ボーン 2 本、表情 1 つ。物理演算のテストでは剛体と関節、錘で形を保つ髪も）を、`e2e/fixtures/vmd.ts` で小さな VMD を組み立てています。WebGL は GPU のない環境でも動くよう、ソフトウェア描画（SwiftShader）で動かします。

## コードの構成

`core/`（純粋な計算）← `engine/`（three.js の実行部）← `ui/`（React の画面）の 3 層で、依存は一方向だけです。考え方・各クラスの役割・つなぎ方は [ARCHITECTURE.md](ARCHITECTURE.md) にまとめています。

```
src/
  main.tsx                  入口: Engine を 1 つ作り、EngineProvider で画面に渡す
  core/                     純粋な計算とデータ
    constants.ts, types.ts  定数とポーズ・キーフレームの型
    events.ts, store.ts     型付きイベントと、小さなストア
    stacking.ts             積み重ね (分離軸判定・高さ・空いている場所)
    hairWeights.ts          髪の形を保つ錘の見つけ方
    keyframeMath.ts         キーフレームの補間
    vpdFormat.ts, sjis.ts   .vpd の書式と Shift-JIS
    timelineMath.ts         タイムラインの目盛り・拡大縮小
  engine/                   three.js の実行部 (クラスごと)
    Engine.ts               組み立てと、画面への窓口
    UiChannel.ts            画面に知らせる状態とお知らせ
    render/                 SceneGraph (場面)・Viewport (描画先と描画ループ)・Effects, postfx (MME 風の後処理)
    world/                  World (置いた物・積み重ね・落下)・Selection (選択)・ColorPicker (パレット)
    view/                   CameraController (カメラ・レイ・視点)・InputController (マウス・タッチ)
    anim/                   Clock (タイムライン)・Keyframes (キーフレーム)・Music (曲)
    mmd/                    MmdLoader・Physics・Stage・Motion (ダンスとカメラ)・Posing (表情とボーン)・Materials (材質)・VpdIO
  ui/                       React の画面
    App.tsx, EngineContext.tsx, styles.css
    components/             TopBar, Menu, ViewportArea, Gizmo, Timeline, BSlider, NumField, Overlays, sidebar/
    hooks/useShortcuts.ts   キーボードショートカット
e2e/                        e2e テスト (Playwright) と、テスト用 PMX を組み立てる fixtures/pmx.ts
```

## しくみ

- 描画は three.js（0.171.0）です。PMX の読み込みには three.js の `MMDLoader` を使っています。`MMDLoader` は r172 で three.js 本体から外されたため、three.js はこれが入っている最後の版に固定しています。MMD の読み込みや後処理などの大きな部品は、初めて使うときに読み込みます（Vite がファイルを分けます）。
- 画面の部品は React で、three.js の場面はエンジン（`src/engine`）が持ちます。エンジンは状態が変わると `UiChannel` のストアに書き、部品は `useUi`（`useSyncExternalStore`）でそれを読んで描き直します。毎フレーム変わるもの（再生中の表情・ボーンの値）は、描き直しを 0.1 秒に 1 回に間引きます。タイムラインとナビゲーションギズモは 2D の canvas に直接描きます。
- 地面は大きな板に専用のシェーダーを当てて描いています。Blender の床のように面は塗らず、`fwidth` で距離に関係なく線幅が一定になるようにアンチエイリアスした 1 単位ごとの細線と 5 単位ごとの太線、X 軸（赤）と Z 軸（青）だけを引き、遠くほど透明にしています。
- MMD の輪郭線と、選択中のオレンジの輪郭線は three.js の `OutlineEffect` です（選んだ物の材質の輪郭線の設定を一時的に変える）。
- 手で動かしたボーンは、モーションのないモデルでは、最初の姿勢に戻してから手の値を当て、`CCDIKSolver`（IK）と付与を計算し直します。物理演算で動く骨はそのままにします。モーションのあるモデルでは、毎フレームのモーションのあとに手の値を当てます。
- モーションの再生（カメラを含む）は three.js の `MMDAnimationHelper` です。モーションは繰り返さずに最後の姿勢で止まる設定にして、タイムラインの時刻に合わせて動かし、飛んだときは物理演算をその姿勢になじませます。
- 物理演算は three.js の `MMDPhysics` と Ammo.js（Bullet の WebAssembly 版）です。`MMDPhysics` は剛体を「拡大縮小していないモデル自身の座標」で扱いますが、縮小したモデルでは剛体を作るとき・置き直すとき（`reset`）・続けて計算するとき（`warmup`）に座標がずれるので、呼ぶ間だけモデルを等倍・親なしにしています（ずれると剛体が遠くへ飛ばされ、髪とスカートが絡まって巻き上がる）。またモデル自身の座標で計算するので、置き場所の加速度を「見かけの重力」として足し、縦軸まわりに回したときは剛体ごとにオイラー力・遠心力・コリオリ力をかけています。モデルを消しても、Ammo.js 側のメモリは解放されません。
- 効果は three.js の `EffectComposer` で後処理しています（`GTAOPass`・`BokehPass`・`UnrealBloomPass` 2 つ・色調の `ShaderPass`・`OutputPass`）。効果を 1 つも使わないときは、後処理を通さずに描きます。
- 影は平行光源のシャドウマップです。物を掴む判定は three.js のレイキャストで、見た目の形どおりに当たります（PMX モデルは、骨やモーフの計算をしない判定用の複製で判定して速くしています）。
- 積み重ねは簡単な重力で処理しています。上から見た足場（回転した長方形どうしを分離軸判定で調べる）が重なる物があればその上に、なければ地面まで落とし、落ちるときは重力加速度で加速して着地で小さく跳ねます。
