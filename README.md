# webgl-grid

WebGL2 のフラグメントシェーダーだけで描いた、無限に続くグリッドと、立方体・トーラス・三角錐を置いて遊べるデモです。

デモ: https://sparklingstadt.github.io/webgl-grid/

## 操作

以下の「形」は、立方体・トーラス・三角錐のどれにも当てはまります。

| 操作 | 内容 |
| --- | --- |
| 右下の「立方体 / トーラス / 三角錐」 | 次に追加する形を選ぶ |
| 「追加」ボタン | 選んだ形を画面中央の近くに置く（最大32個。8色のうち使われていない色を優先して割り当て） |
| 何もない地面を長押し（スマホ） | 選んだ形をその場所に置く（ほかの形と重なる位置なら、その上に積まれる） |
| 形をドラッグ（スマホは長押ししてから） | 形を動かす（どちらのモードでも可。掴んでいる形は明るく表示）。スマホで長押しせずにすぐ指を動かすと、カメラの操作になる。ほかの形の上まで運ぶとその上に積まれ、上に載っている形も一緒に運ばれる。持ち上げた高さのまま運び、離すと下に落ちる |
| 形を Shift+ドラッグ | 縦軸まわりに回す（上に載っている形も一緒に回る） |
| 形を指で押さえ、もう1本の指でひねる（スマホ） | 縦軸まわりに回す（ひねった向きに回る） |
| 形をクリック | その形の色を次の色に変える |
| 形をタップ（スマホ） | 8色のパレットが出て、色を選べる（パレットの外を触ると閉じる） |
| 形をダブルクリック / ダブルタップ | その形を削除する（上に載っていた形は下に落ちる） |
| ドラッグ（回転モード） | 注視点を中心にカメラを回す |
| ドラッグ（移動モード） | 地面に沿ってカメラを平行移動する |
| ホイール / ピンチ（スマホ） | ズームイン / ズームアウト（ピンチは形のない場所で） |
| 「回転」「移動」ボタン | カメラのドラッグ操作を切り替える |
| 「リセット」ボタン | 視点を戻し、原点の立方体1個だけに戻す |

タッチ操作にも対応しています。

## しくみ

- 画面全体を覆う三角形を1枚描き、ピクセルごとにレイを飛ばしています。
- 地面（y = 0）との交差位置からグリッドを描画しています。`fwidth` を使って、距離に関係なく線幅が一定になるようにアンチエイリアスしています。
- 1単位ごとの細線と5単位ごとの太線を引き、X軸を赤、Z軸を青で示しています。
- 形の位置・色・回転角・種類は uniform 配列でシェーダーに渡し、レイを形ごとのローカル座標に直して判定したうえで、一番手前で当たったものを表示しています。平行光源による陰影と、地面やほかの形への影もつけています。
  - 立方体（1×1×1）: レイと箱の交差判定
  - トーラス（寝かせた輪。高さ 0.3）: 囲む箱の中だけを距離関数でレイマーチ
  - 三角錐（底面は正三角形、高さ 0.8）: 底面と3つの側面の半空間の共通部分として判定
- 形のドラッグは、JavaScript 側でシェーダーと同じカメラのレイと同じ交差判定を使って当たりを調べ、掴んだ点の高さの水平面に沿って動かしています。トーラスの穴の部分は掴めません。
- 積み重ねは簡単な重力で処理しています。上から見て足場（どの形も 1×1 の正方形として扱い、回転した正方形どうしを分離軸判定で調べる）が重なる形があればその上に、なければ地面まで落とします。載る高さは下の形の高さで決まり、三角錐の上にも載せられます。落ちるときは重力加速度で加速し、着地で小さく跳ねるアニメーションをつけています。上に載せるときは、少し高くまで跳び上がってから同じ重力で着地します。

## ローカルで動かす

`index.html` 1ファイルだけで動き、外部ライブラリは使っていません。ブラウザで直接開くか、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
```

WebGL2 に対応したブラウザが必要です。
