# webgl-grid

three.js で描いた、無限に続くグリッドの上に、立方体・トーラス・三角錐や MMD モデル（.pmx）を置いて、モーション（.vmd）で踊らせたりできるデモです。

デモ: https://sparklingstadt.github.io/webgl-grid/

## 操作

以下の「物」は、立方体・トーラス・三角錐・読み込んだ PMX モデルのどれにも当てはまります（色を変える操作は形だけ）。

| 操作 | 内容 |
| --- | --- |
| 右下の「立方体 / トーラス / 三角錐」 | 次に追加する形を選ぶ |
| 「追加」ボタン | 選んだ形を画面中央の近くに置く（最大32個。8色のうち使われていない色を優先して割り当て） |
| 「MMD…」ボタン | .pmx とテクスチャ画像をまとめて選ぶと、モデルを画面中央の近くに置く（高さは立方体2個分にそろえる）。.vmd も一緒に選ぶとそのモデルで再生し、.vmd だけを選ぶと置いてあるモデル全員で再生する |
| 何もない地面を長押し（スマホ） | 選んだ形をその場所に置く（ほかの物と重なる位置なら、その上に積まれる） |
| 物をドラッグ（スマホは長押ししてから） | 物を動かす（どちらのモードでも可。掴んでいる物は明るく表示）。スマホで長押しせずにすぐ指を動かすと、カメラの操作になる。ほかの物の上まで運ぶとその上に積まれ、上に載っている物も一緒に運ばれる。持ち上げた高さのまま運び、離すと下に落ちる |
| 物を Shift+ドラッグ | 縦軸まわりに回す（上に載っている物も一緒に回る） |
| 物を指で押さえ、もう1本の指でひねる（スマホ） | 縦軸まわりに回す（ひねった向きに回る） |
| 形をクリック | その形の色を次の色に変える |
| 形をタップ（スマホ） | 8色のパレットが出て、色を選べる（パレットの外を触ると閉じる） |
| 物をダブルクリック / ダブルタップ | その物を削除する（上に載っていた物は下に落ちる） |
| ドラッグ（回転モード） | 注視点を中心にカメラを回す |
| ドラッグ（移動モード） | 地面に沿ってカメラを平行移動する |
| ホイール / ピンチ（スマホ） | ズームイン / ズームアウト（ピンチは物のない場所で） |
| 「回転」「移動」ボタン | カメラのドラッグ操作を切り替える |
| 「リセット」ボタン | 視点を戻し、原点の立方体1個だけに戻す（読み込んだモデルも消える） |

タッチ操作にも対応しています。

## MMD モデルとモーションの読み込み

- 「MMD…」を押して、モデルの `.pmx` と、モデルが使うテクスチャ画像（`.png` `.bmp` `.tga` `.spa` `.sph` など）を**まとめて**選んでください。テクスチャがサブフォルダにある場合も、画像ファイルを一緒に選べばファイル名で対応づけます。
- 選んだファイルはブラウザの中だけで読み込み、どこにも送信しません。ページを再読み込みすると消えます。
- 見つからないテクスチャがあると、画面上部にファイル名を表示します（モデルはテクスチャなしで表示されます）。
- MMD の輪郭線を表示します。輪郭線の太さ・色と、どの材質に付けるかは .pmx の設定に従います。
- MMD の物理演算（髪やスカートの揺れ）が動きます。モデルを運ぶと髪がなびき、落ちるときはふわっと浮きます。剛体のないモデルは揺れません。
- モーション（.vmd）は、モデルと一緒に選ぶとそのモデルで、.vmd だけを選ぶと置いてあるモデル全員で、繰り返し再生します。骨と表情（モーフ）の動きを再生し、足の IK や連動する骨も計算します。カメラや照明の動きは使いません。
- モーションの骨や表情の名前が、モデルのものと1つも合わない場合は、その旨を表示します。
- モーションで体が動いても、掴む判定は読み込んだときの姿勢のままです（大きく動くダンスでは、見た目と掴める場所がずれます）。
- モデルの利用規約（再配布の禁止など）は、それぞれのモデルの readme に従ってください。このリポジトリでは `.pmx` と `げのげ式初音ミク/` を `.gitignore` で除外しています。

## しくみ

- 描画は three.js（0.171.0）です。PMX の読み込みには three.js の `MMDLoader` を使っています。`MMDLoader` は r172 で three.js 本体から外されたため、three.js はこれが入っている最後の版に固定しています。
- 地面は大きな板に専用のシェーダーを当てて描いています。`fwidth` を使って、距離に関係なく線幅が一定になるようにアンチエイリアスし、1単位ごとの細線と5単位ごとの太線、X軸（赤）と Z軸（青）を引いて、遠くほど透明にして背景に溶かしています。
- MMD の輪郭線は three.js の `OutlineEffect` で描いています（法線方向に少し膨らませた裏面を輪郭線の色で重ねる方法）。立方体などの形・地面には付けません。
- モーションの再生は three.js の `MMDAnimationHelper` です（`MMDLoader` と同じく r172 で外されたため 0.171.0 のものを使用）。物理演算はモーションのあとに計算します。
- 物理演算は three.js の `MMDPhysics` と Ammo.js（Bullet の WebAssembly 版）です。Ammo.js は約 1MB あるので、剛体を持つモデルを初めて読み込んだときに CDN から取ってきます。物理演算かモーションのあるモデルが置かれているあいだだけ、毎フレーム計算して描き直します。
  - `MMDPhysics` は、拡大縮小したモデルを、モデル自身の座標で計算します。そのままでは置き場所を動かしても揺れないので、置き場所の加速度をモデルの向き・単位に直して「見かけの重力」として足しています（強さは `INERTIA`）。縦軸まわりに回したときの揺れは計算していません。
  - モデルを消しても、Ammo.js 側のメモリは解放されません（後片付けの仕組みがないため）。
- 影は平行光源のシャドウマップです。地面の影は、グリッドの上に重ねた影だけを描く板で表示しています。
- 物を掴む判定は three.js のレイキャストで、見た目の形どおりに当たります（トーラスの穴やモデルの隙間は掴めません）。PMX モデルは、骨やモーフの計算をしない判定用の複製で判定して速くしています。
- 積み重ねは簡単な重力で処理しています。上から見た足場（形は 1×1、モデルは包む箱の大きさの長方形。回転した長方形どうしを分離軸判定で調べる）が重なる物があればその上に、なければ地面まで落とします。載る高さは下の物の高さで決まります。落ちるときは重力加速度で加速し、着地で小さく跳ねるアニメーションをつけています。上に載せるときは、少し高くまで跳び上がってから同じ重力で着地します。

## ローカルで動かす

`index.html` 1ファイルで動きます。three.js と Ammo.js は CDN（jsDelivr）から読み込むので、インターネット接続が必要です。ES モジュールを使っているので、静的サーバーで配信して開いてください。

```bash
python3 -m http.server 8000
```

WebGL2 に対応したブラウザが必要です。URL に `?debug` を付けて開くと、動作確認用に中の状態をブラウザのコンソールから触れます。
