# webgl-grid

WebGL2 のフラグメントシェーダーだけで描いた、無限に続くグリッドと立方体のデモです。

デモ: https://sparklingstadt.github.io/webgl-grid/

## 操作

| 操作 | 内容 |
| --- | --- |
| 立方体をドラッグ（スマホは長押ししてから） | 立方体を動かす（どちらのモードでも可。掴んでいる立方体は明るく表示）。スマホで長押しせずにすぐ指を動かすと、カメラの操作になる。ほかの立方体の上まで運ぶとその上に積まれ、上に載っている立方体も一緒に運ばれる。持ち上げた高さのまま運び、離すと下に落ちる |
| 何もない地面を長押し（スマホ） | その場所に立方体を置く（ほかの立方体と重なる位置なら、その上に積まれる） |
| 立方体を Shift+ドラッグ | 縦軸まわりに回す（上に載っている立方体も一緒に回る） |
| 立方体を指で押さえ、もう1本の指でひねる（スマホ） | 縦軸まわりに回す（ひねった向きに回る） |
| 立方体をクリック / タップ | その立方体の色を次の色に変える |
| 立方体をダブルクリック / ダブルタップ | その立方体を削除する（上に載っていた立方体は下に落ちる） |
| ドラッグ（回転モード） | 注視点を中心にカメラを回す |
| ドラッグ（移動モード） | 地面に沿ってカメラを平行移動する |
| ホイール / ピンチ（スマホ） | ズームイン / ズームアウト（ピンチは立方体以外の場所で） |
| 右下のボタン | 回転・移動モードの切り替え、立方体の追加（最大32個。8色のうち使われていない色を優先して割り当て）、リセット（視点を戻し、立方体を原点の1個に戻す） |

タッチ操作にも対応しています。

## しくみ

- 画面全体を覆う三角形を1枚描き、ピクセルごとにレイを飛ばしています。
- 地面（y = 0）との交差位置からグリッドを描画しています。`fwidth` を使って、距離に関係なく線幅が一定になるようにアンチエイリアスしています。
- 1単位ごとの細線と5単位ごとの太線を引き、X軸を赤、Z軸を青で示しています。
- 立方体はレイと箱の交差判定で描いています。位置・色・回転角は uniform 配列でシェーダーに渡し、レイを立方体ごとのローカル座標に直して判定したうえで、一番手前で当たったものを表示しています。平行光源による陰影と、地面やほかの立方体への影もつけています。
- 立方体のドラッグは、JavaScript 側でシェーダーと同じカメラのレイを作って当たり判定し、掴んだ点の高さの水平面に沿って動かしています。
- 積み重ねは簡単な重力で処理しています。上から見て足場が重なる立方体（回転した正方形どうしを分離軸判定で調べる）があればその上に、なければ地面まで落とします。落ちるときは重力加速度で加速し、着地で小さく跳ねるアニメーションをつけています。上に載せるときは、少し高くまで跳び上がってから同じ重力で着地します。

## ローカルで動かす

`index.html` 1ファイルだけで動き、外部ライブラリは使っていません。ブラウザで直接開くか、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
```

WebGL2 に対応したブラウザが必要です。
